# BGLike

두 사람이 만드는 Godot 4 싱글 플레이 전술 RPG의 개발 작업명입니다. 게임의 정식 이름과 세계관은 첫 플레이 가능 구간을 만든 뒤 결정합니다.

개발 중인 상업용 PC 게임입니다. 아직 출시하지 않았습니다. 기능과 화면은 변경될 수 있습니다.

## 시작

- Godot 4.7.2 Standard와 Git LFS가 필요합니다. 이미 설치돼 있으면 그대로 씁니다.
- `git lfs install`을 한 번 실행하고 저장소를 복제합니다.
- 저장소 안에서 `git config core.hooksPath .githooks`를 한 번 실행합니다. 커밋 제목 형식 검사와 Git LFS hook이 함께 켜집니다.
- `project.godot`을 Godot에서 엽니다.
- F6으로 현재 장면을, F5로 메인 장면을 실행합니다.

명령줄에서는 다음으로 확인합니다.

```sh
make godot-install
make check
```

기존 편집기는 `GODOT=/Applications/Godot.app/Contents/MacOS/Godot make check`로 검사합니다.
플랫폼별 설치, 버전 검사와 캐시 없는 실행은 [공통 환경](docs/ENVIRONMENT.md)을 따릅니다.

문서·관리 파일만 바뀌면 공백과 Python 검사를 수행합니다. CI의 엔진 선택과 알림 조건은 [CI 구성](docs/CI.md)을 따릅니다.

## 협업 규칙

- 처음이라면 [참여 안내](CONTRIBUTING.md)를 읽습니다. Issue, 브랜치, 커밋, 문서, 개발 규칙을 한 장으로 요약했습니다.
- 작업은 GitHub Issue에 목표와 완료 조건을 적고 시작합니다. 작은 브랜치에서 PR을 열고 동료 검토 후 squash merge합니다.
- [협업 절차](docs/WORKFLOW.md)와 [AI 에이전트 지침](AGENTS.md)을 따릅니다. Claude Code는 `CLAUDE.md`에서 같은 지침을 읽습니다.
- 비공개 저장소의 현재 GitHub 요금제로는 `main` 보호 규칙을 켤 수 없습니다. 자세한 상태와 대신 지키는 운영 규칙은 협업 절차에 있습니다.
- `.godot/` 캐시는 커밋하지 않습니다. 장면과 스크립트 등 원본 파일은 커밋합니다. `.gitattributes`에 지정된 바이너리는 Git LFS로 관리합니다.

PR의 실행 검증은 GitHub Actions가 수행합니다. [Godot 캐시 설명](docs/CI_CACHE.md)은 CI 검사 서버와 Codex 원격 구현 환경의 역할을 구분합니다.

## 현재 범위

Issue #12의 M1 전투 프로토타입을 단계별로 만듭니다. 기반은 640×360 기준 화면, 정수 배율과 픽셀 필터, 10×10 평지 아이소메트릭 격자, 아군·적 각 전사와 궁수의 고정 배치입니다. 메인 장면을 실행하면 임시 도형 격자와 유닛 4명이 바로 보입니다.

2단계에서 `d20 + 민첩` 이니셔티브, 연속한 같은 편의 턴 묶음, 유닛별 이동·행동·보조 행동·반응 자원, 턴 종료를 추가했습니다. 아군 묶음에서는 왼쪽 위 초상을 눌러 유닛을 전환합니다. 선택 테두리와 오른쪽 위의 자원 표시가 함께 바뀝니다. 전환은 자원을 회복하지 않습니다. 턴 종료는 현재 유닛만 끝내며, 묶음의 전원이 끝내면 다음 묶음으로 넘어갑니다.

3단계에서 명중·유리/불리·내성·대결의 판정과 명중률 미리보기를 추가했습니다. 아군 턴에 지도 위의 적 도형을 한 번 누르면 오른쪽에 적의 HP·AC·상태와 명중률이 나옵니다. 기절한 대상과 원거리 공격자 옆의 적을 반영하고, 사거리 밖이면 0%와 이유를 표시합니다. 미리보기는 주사위를 굴리거나 자원을 쓰지 않습니다. 판정 결과는 주사위·선택 값·합계를 보존합니다.

4단계 작업에서는 빈 칸을 한 번 눌러 이동 경로를 보고 같은 칸을 다시 눌러 이동합니다. 유닛 몸통에 가려진 빈 칸은 오른쪽 아래 이동 버튼을 고른 뒤 선택합니다. 이동은 8방향, 칸마다 비용1이며 남은 이동을 나눠 쓸 수 있습니다. 공격은 적을 한 번 눌러 미리보기, 같은 적을 다시 눌러 실행합니다. 겹쳐 보이는 유닛은 앞에 그려진 쪽을 선택합니다. 사거리 밖이나 자원이 없으면 실행하지 않습니다. 아래 스킬 패널에서 스킬·밀치기·물약을 선택하고, 자기 대상 동작은 같은 버튼을 다시 눌러 사용합니다. 기본 배치에서는 적이 사거리 밖이므로 먼저 이동해야 합니다.

기회 공격은 상대가 스스로 인접 칸을 벗어나기 전에 판정합니다. 아군은 확인 창에서 사용할지 고르고, 적 반응은 자동입니다. 반응을 기다리는 동안 다른 입력을 잠급니다. 밀치기와 물러서며 쏘기의 이동은 기회 공격을 받지 않습니다. 스킬과 물약의 전투당 횟수는 턴 전환으로 회복하지 않습니다. HP0은 즉시 전투 불능이고 턴 순서에서 제거합니다. 기절한 다음 자기 턴은 자동으로 건너뛴 뒤 기절을 풉니다.

흘려내기와 충격 화살의 내성 DC는 `8 + 숙련2 + 능력치3 = 13`입니다. 전사 민첩+1의 흘려내기 성공률은45%이며, 피해를 굴리기 전에 확인합니다. 충격 화살은 빗나가도 행동과 사용 횟수를 모두 소비합니다.

5단계에서는 화면 아래에 행동·보조 행동·반응 컨테이너를 둡니다. 제목의 ● ▲ ◆는 자원을 쓰면 ○ △ ◇로 바뀝니다. 버튼 오른쪽의 색 기호는 비용이고, 오른쪽 위 숫자 배지는 남은 전투당 횟수입니다. 궁수는 반응 컨테이너를 숨깁니다. 자기 턴에 반응 항목을 눌러도 실행되지 않습니다. 적 턴에는 마지막 아군의 스킬 패널이 회색으로 남습니다.

자원 기호 옆에는 남음/사용함을 표시합니다. 왼쪽 가운데 설명 패널은 선택한 스킬의 효과·비용·전투당 횟수·사용법·현재 사용할 수 없는 이유를 보여 줍니다. 버튼과 자원 제목에도 설명이 있습니다. 비용은 턴 자원이며 자기 턴 시작에 회복합니다. 횟수 배지는 이번 전투에 남은 횟수이며 턴 시작에 회복하지 않습니다.

긴 설명은 설명 패널에서 마우스 휠로 읽습니다. 설명 영역은 전투 로그 위의 고정된 공간을 사용합니다.

이동 버튼에 남은 칸 수를 표시합니다. 버튼을 고르면 이동 가능한 칸은 파랑, 도착 후 기본 공격할 적이 있는 칸은 초록입니다. 칸을 한 번 누르면 경로 길이·남을 이동력·도착 시 공격 가능한 적 수를 표시하고, 공격 가능한 적의 테두리를 표시합니다. 행동이 없거나 사거리가 닿지 않으면 이유를 표시합니다. 이동에 성공하면 기본 공격 선택으로 돌아가므로 바로 적을 눌러 공격할 수 있습니다. 이동은 행동을 소비하지 않으므로 이동→공격→남은 이동 순으로 사용할 수 있습니다. 이동 중 기회 공격에는 주의해야 합니다.

오른쪽 위는 현재 유닛의 HP·AC·이동·상태를 표시합니다. 적 미리보기 중에는 적 정보로 바뀝니다. 왼쪽 아래의 전투 로그는 최근 3줄을 표시하며, 유리·불리의 두 주사위, 내성·대결·반응과 표식 추가 피해를 기록합니다. 유닛 위에 HP 바, 기절 글자와 표식 ◎를 표시합니다. 판정과 HP 변화는 임시 숫자 팝업으로도 보입니다. 한쪽이 전멸하면 승리·패배 창에서 재시작할 수 있습니다.

6단계에서 적은 이니셔티브 순서대로 자동 행동하고 턴을 마칩니다. 적 전사는 HP 절반 이하에서 숨 고르기를 먼저 쓰고, 가장 가까운 아군에게 접근해 공격합니다. 회복을 쓰지 않았고 인접한 대상이 남으면 몰아치기로 한 번 더 공격합니다. 적 궁수는 인접한 아군에게서 벗어나며, 물러서며 쏘기가 남아 있으면 먼저 씁니다. 공격 전 표식을 걸고, 충격 화살이 남아 있으면 기본 공격 대신 씁니다. 사거리 안의 대상은 HP가 낮은 쪽을 고릅니다. 적 행동 사이에 짧은 간격을 두며, 아군 반응 확인 창에서는 선택할 때까지 기다립니다.

아군은 파랑, 적은 빨강이며 검과 활로 전사와 궁수를 구분합니다. 몸통에 가려진 빈 칸은 오른쪽 아래 이동 버튼을 고른 뒤 선택합니다. 아군 턴은 실행 가능한 이동·행동·보조 행동이 없어도 자동으로 종료하지 않습니다. 턴 종료 버튼의 색만 강조합니다. 적 턴에는 이동·턴 종료 버튼이 잠깁니다. 편집기 직접 조작 확인과 7단계 전체 검수는 별도로 기록합니다.
