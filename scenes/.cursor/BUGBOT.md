# BGLike 게임·화면 영역 리뷰

- `.tscn`·`.tres`·`.gd`·`.uid`와 필요한 import 설정의 경로·호환성을 확인한다. 메인 장면·리소스 로딩이 깨지는 결함을 우선한다.
- Godot 리소스 이름은 `snake_case`를 사용한다. 새 GDScript의 가능한 타입을 명시한다. 엔진 업그레이드·애드온·Autoload·추상화는 합의된 필요가 있어야 한다.
- 전투 action·턴·주사위·hex-grid·진행·loot의 공개 동작과 호출자 호환성을 확인한다. 기획의 미확정 수치를 새 규칙으로 만들지 않는다.
- 입력·표시·tooltip·후속 상태와 실제 애니메이션 완료의 회귀를 확인한다. 테스트 성공이 조작감·화면 가독성의 증거는 아니다.
