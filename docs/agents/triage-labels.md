# Triage Labels

분류 스킬이 사용하는 다섯 역할을 GitHub 라벨 이름에 연결합니다. 사용자 선택에 따라 기본 이름을 사용합니다.

| 스킬의 역할 | GitHub 라벨 이름 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 담당자가 작업과 처리 방법을 검토해야 합니다. |
| `needs-info` | `needs-info` | 판단에 필요한 답이나 자료를 기다립니다. |
| `ready-for-agent` | `ready-for-agent` | 범위와 완료 조건이 정해져 에이전트가 구현할 수 있습니다. |
| `ready-for-human` | `ready-for-human` | 사람이 수행해야 하는 작업입니다. |
| `wontfix` | `wontfix` | 이 작업을 진행하지 않습니다. |

## 적용 범위

- 스킬의 분류 역할에 대응하는 이름은 표를 참조합니다. 이 매핑만으로 라벨 적용 권한이 생기지는 않습니다.
- 현재 일반 작업은 [협업 규칙](../WORKFLOW.md)의 `claude` 라벨 운영을 따릅니다. 이 표의 추가는 현재 Issue를 다시 분류하거나 원격 라벨을 만드는 요청이 아닙니다.
- 실제 분류 라벨을 도입하려면 `claude`만 사용하는 기존 규칙을 바꾸는 별도 작업에서 [협업 규칙](../WORKFLOW.md)을 갱신하고 문서 PR의 합의를 확인합니다. 그 전에는 분류 결과를 Issue 코멘트로 남기며 원격 라벨을 생성하거나 적용하지 않습니다.
- `ready-for-agent`는 준비 상태입니다. `claude` 라벨을 붙이는 실행 요청을 대신하지 않습니다.
- 라벨 도입 후에도 원격에 `wontfix`가 있으면 그 라벨을 사용합니다. 같은 역할의 라벨을 중복으로 만들지 않습니다.
