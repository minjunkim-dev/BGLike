## 1. 이 문서를 쓰는 법

- 새 캐릭터나 몬스터를 기획할 때 3~6장의 시트를 복사해 채웁니다.
- 시트의 수치와 규칙이 정해지면 전투 시스템 기획서나 게임 구조 기획서로 옮깁니다. 이 문서에는 컨셉, 장단점, 역할처럼 **왜 그렇게 만들었는지**를 남깁니다.
- 세계관과 이야기는 M7에서 정합니다. 그 전까지 이름은 역할을 드러내는 가칭을 씁니다.

## 2. 디자인 원칙

| 원칙 | 상태 | 내용 |
|---|---|---|
| 컨셉 필수 | ✅ | 모든 캐릭터와 몬스터는 컨셉을 가집니다. 컨셉이 스킬과 수치를 정하는 기준입니다 |
| 컨셉 먼저 | ✅ | 캐릭터는 소설 같은 추상 컨셉을 먼저 잡고, 그 컨셉에서 스킬을 만듭니다 (4-1) |
| 장단점 필수 | ✅ | 모든 유닛은 장점과 단점을 함께 가집니다. 단점이 없는 유닛은 만들지 않습니다 |
| 질문 하나 | 🟡 | 몬스터 하나는 플레이어에게 전술 질문 하나를 던집니다. 예: "누구부터 잡을까?", "어디에 설까?" |
| 기존 동작 재사용 | 🟡 | 새 규칙보다 기존 동작(기절, 밀치기, 기회 공격, 유리/불리, 내성 굴림)의 조합을 먼저 찾습니다 |
| 대응 수단 | 🟡 | 몬스터의 장점마다 그것을 받아칠 아군 수단이 하나 이상 있어야 합니다 |

## 3. 공통 항목

캐릭터와 몬스터가 모두 채우는 항목입니다.

| 항목 | 내용 |
|---|---|
| 이름 | 가칭 |
| 컨셉 | 캐릭터는 추상 컨셉 한 줄 (4-2). 몬스터의 컨셉 형식은 ❓ |
| 역할 | 캐릭터는 4-4, 몬스터는 5-2 |
| 장점 | 2~3개. 수치나 동작으로 드러나야 함 |
| 단점 | 1~2개. 플레이어가 화면에서 알아챌 수 있어야 함 |
| 능력치 | 힘, 민첩, 건강, 정신의 보정값 |
| 전투 수치 | HP, AC, 이동력 |
| 기본 공격 | 근접/원거리, 공격 능력치, 피해, 사거리, 기회 공격 가능 여부 |
| 스킬 | 이름, 소비 자원(행동/보조 행동/반응), 횟수, 대상, 효과 |
| 외형 메모 | 실루엣과 색만. 에셋 출처는 M2 사용자 타겟 뒤에 정함 ❓ |

## 4. 캐릭터

### 4-1. 디자인 순서 ✅

캐릭터는 **추상 컨셉 → 스킬 → 수치** 순서로 만듭니다. 기능(탱커가 필요하다)에서 시작하지 않고 인물(무리에서 쫓겨난 늑대인간)에서 시작합니다.

| 순서 | 할 일 | 결과물 |
|---|---|---|
| 1 | 추상 컨셉을 한 줄로 씁니다 | 컨셉 (4-2) |
| 2 | 컨셉을 풀어 키워드 3~5개를 뽑습니다 | 키워드 |
| 3 | 키워드마다 전투에서 어떻게 드러날지 정합니다 | 스킬, 장점, 단점 (4-3) |
| 4 | 나온 스킬을 보고 역할을 확인합니다 | 역할 (4-4) |
| 5 | 수치를 정합니다 | 능력치, HP, AC, 기본 공격 |

- 스킬, 장점, 단점은 각각 **어느 키워드에서 나왔는지** 적습니다. 근거 키워드가 없는 스킬은 컨셉과 맞지 않는 스킬입니다.
- 역할은 스킬에서 따라 나옵니다. 파티에 필요한 역할이 정해져 있으면 1단계 전에 정해 두고, 4단계에서 맞는지 확인합니다 🟡.

### 4-2. 추상 컨셉 ✅

추상 컨셉은 소설의 인물 소개처럼 쓴 한 줄입니다.

> 예: 무리에서 쫓겨난 늑대인간 · 세상에서 최초로 태어난 마법사

좋은 추상 컨셉의 조건 🟡:

| 조건 | 이유 | 나쁜 예 → 좋은 예 |
|---|---|---|
| **정체**와 **사연**이 함께 있음 | 정체만 있으면 흔한 직업이 되고, 사연이 개성을 만듦 | 늑대인간 → 무리에서 **쫓겨난** 늑대인간 |
| 결핍이나 갈등이 들어 있음 | 단점의 근거가 됨 | 강한 마법사 → **최초로** 태어난 마법사 (배울 곳이 없음) |
| 키워드가 3개 이상 나옴 | 스킬 3개를 만들 재료 | |
| 역할이나 수치를 직접 말하지 않음 | 기능에서 시작하면 컨셉이 수치 설명이 됨 | 방패를 든 탱커 |

- 늑대인간, 마법사 같은 일반 명사는 써도 됩니다. BG3나 다른 작품의 고유 인물·종족 이름은 쓰지 않습니다.
- 캐릭터 컨셉은 세계관(M7)보다 먼저 나옵니다. 컨셉이 세계관을 미리 정하는 셈이므로, 컨셉들이 한 세계에 함께 있을 수 있는지 M7에서 확인합니다 ❓.

### 4-3. 컨셉에서 스킬 만들기

키워드를 전투 동작으로 옮길 때 쓰는 질문입니다 🟡.

| 질문 | 나오는 것 |
|---|---|
| 이 인물이 가장 잘하는 것은? | 대표 스킬, 장점 |
| 이 인물이 잃은 것, 못하는 것은? | 단점 |
| 이 인물은 언제 가장 강해지나? | 조건부 스킬 (유리, 추가 피해) |
| 이 인물은 동료와 어떻게 지내나? | 짝 (아군 연계) |
| 이 인물을 몰아붙이면 어떻게 되나? | 위기 때 쓰는 스킬, 약한 상대 |

스킬은 기존 동작(행동, 보조 행동, 반응, 유리/불리, 내성 굴림, 기절, 밀치기)으로 먼저 만듭니다. 새 규칙이 필요하면 따로 적습니다.

#### 예시: 무리에서 쫓겨난 늑대인간

> 디자인 순서를 보여 주는 예시입니다. 채택한 캐릭터가 아니며 수치는 정하지 않았습니다.

| 키워드 | 전투에서 | 종류 | 새 규칙 |
|---|---|---|---|
| 혼자 | 인접한 아군이 없으면 공격에 유리 | 장점 | 상시 효과 (지금 스킬은 모두 직접 씀) |
| 혼자 | 아군 곁에 서면 힘을 못 냄. 전사와 붙어 싸우기 어려움 | 단점 | |
| 사냥 | HP가 절반 이하인 대상을 맞히면 피해 추가 | 스킬 | |
| 짐승의 몸 | 보조 행동으로 변신. 막당 1회. 이동력 증가, 대신 물약을 못 씀 | 스킬, 단점 | 변신 상태 |
| 쫓겨난 분노 | 정신 보정값이 낮음. 기절에 약함 | 단점 | |

→ 스킬이 혼자 사냥하는 쪽으로 모이므로 역할은 **딜러**입니다 (4단계).

#### 예시: 세상에서 최초로 태어난 마법사

| 키워드 | 전투에서 떠올릴 수 있는 것 |
|---|---|
| 최초 | 마법의 이름도 규칙도 없음 → 스킬 효과가 주사위로 정해짐 |
| 배울 곳이 없음 | 스킬 수가 적거나, 막을 거치며 새로 깨우침 |
| 혼자 아는 힘 | 아군을 강화하는 스킬이면 서포터, 적을 약화하면 서포터 또는 딜러 |

### 4-4. 역할 ✅

캐릭터마다 장기인 **역할**이 하나 있습니다.

| 역할 | 하는 일 | 지금 캐릭터 |
|---|---|---|
| 탱커 | 적의 공격을 받아 내고 버팀. 아군 딜러를 지킴 | 전사 |
| 딜러 | 적을 빠르게 전투 불능으로 만듦 | 궁수 |
| 서포터 | 아군을 회복·강화하거나 적을 약화함 | 없음 ❓ |

> 지금 적 AI는 사거리 안에서 HP가 낮은 대상을 노립니다 ([전투 시스템 기획서 7장](COMBAT_DESIGN.md#7-적-ai)). 그래서 전사가 공격을 끌어 줄 수단이 없습니다. 탱커가 역할을 하려면 도발 같은 스킬이나 AI 조준 규칙이 필요합니다 ❓ ([게임 구조 기획서 5장](GAME_STRUCTURE.md#5-캐릭터)).

### 4-5. 캐릭터 시트

공통 항목(3장)에 아래를 더합니다.

| 항목 | 내용 |
|---|---|
| 키워드 | 컨셉에서 뽑은 3~5개 |
| 스킬별 근거 | 스킬마다 근거 키워드 |
| 역할 | 탱커 / 딜러 / 서포터 |
| 플레이 감각 | 이 캐릭터로 플레이어가 하는 판단. 예: "언제 버티고 언제 되받아칠까" |
| 짝 | 다른 캐릭터와 함께 쓸 때 생기는 연계 |
| 약한 상대 | 이 캐릭터가 혼자서는 상대하기 어려운 몬스터 |

### 4-6. 지금 캐릭터

수치는 [전투 시스템 기획서 2장·5장](COMBAT_DESIGN.md#2-시험-전투) 기준입니다.

전사와 궁수는 추상 컨셉 없이 스킬부터 만들었습니다. 추상 컨셉을 정하면 지금 스킬이 그 컨셉에서 나올 수 있는지 거꾸로 확인하고, 맞지 않는 스킬은 이름이나 효과를 바꿀지 정합니다 ❓.

#### 전사

| 항목 | 내용 |
|---|---|
| 추상 컨셉 | ❓ |
| 기능 요약 | 앞에서 버티고 되받아치는 근접 전사 |
| 역할 | 탱커 ✅ |
| 장점 | 높은 AC(16). 흘려내기로 명중을 피함. 기회 공격으로 적의 이동을 막음. 숨 고르기로 스스로 회복 |
| 단점 | 사거리가 인접뿐. 정신 −1이라 정신 내성(기절)에 약함. 적의 조준을 끌어오지 못함 |
| 플레이 감각 🟡 | 어디에 서서 적의 길을 막을까 |
| 짝 🟡 | 궁수 앞을 막아 궁수가 불리 없이 쏘게 함 |

#### 궁수

| 항목 | 내용 |
|---|---|
| 추상 컨셉 | ❓ |
| 기능 요약 | 거리를 지키며 표식한 적을 끝내는 사수 |
| 역할 | 딜러 ✅ |
| 장점 | 사거리 1~6. 표식으로 한 대상에 피해를 몰아줌. 충격 화살로 기절. 물러서며 쏘기로 기회 공격 없이 빠짐 |
| 단점 | AC가 낮음(14). 적이 붙으면 원거리 공격이 불리. 기회 공격을 하지 못함 |
| 플레이 감각 🟡 | 누구를 표식하고, 언제 거리를 벌릴까 |
| 짝 🟡 | 전사가 묶어 둔 적을 표식으로 마무리 |

## 5. 몬스터

### 5-1. 등급 ✅

몬스터를 강한 정도로 나눕니다. 지금은 두 등급만 둡니다.

| 등급 | 뜻 | 추가 항목 |
|---|---|---|
| 일반 | 스테이지에 여럿 나오는 기본 몬스터 | 없음 |
| 보스 | 강한 몬스터. 일반 몬스터보다 확실히 강함 | 6장의 높은 체력, 패배 조건, 패턴, 기믹 |

- 그 사이 등급(예: 정예)은 필요해지면 다시 논의합니다 ❓.
- 아이템 등급과는 별개입니다. 아이템 등급은 [게임 구조 기획서 4-7](GAME_STRUCTURE.md#4-7-보류한-것-)에서 보류 중입니다.

### 5-2. 몬스터 역할 🟡

캐릭터의 역할과 같은 말을 쓰되, 몬스터는 위치에 따른 역할을 함께 적습니다.

| 역할 | 예 |
|---|---|
| 근접 | 지금의 적 전사 |
| 원거리 | 지금의 적 궁수 |
| 지원 | 동료 회복·강화, 아군 약화 ❓ |

### 5-3. 일반 몬스터 시트

공통 항목(3장)에 아래를 더합니다.

| 항목 | 내용 |
|---|---|
| 등급 | 일반 |
| 던지는 질문 | 이 몬스터가 나오면 플레이어가 고민할 것 |
| 대응 수단 | 장점을 받아칠 아군 스킬·동작 |
| AI | 우선 대상, 이동 방식, 스킬 쓰는 조건 |
| 등장 막 | 1 / 2 / 3. 막별 적 강화는 [게임 구조 기획서 2-3](GAME_STRUCTURE.md#2-3-막별-적-강화-)을 따름 |
| 드랍 | 기본은 몬스터당 추가 드랍 35% ([게임 구조 기획서 4-5](GAME_STRUCTURE.md#4-5-드랍-확률-)) |

### 5-4. 지금 몬스터

지금 적은 아군과 같은 전사와 궁수를 씁니다 ([게임 구조 기획서 8장](GAME_STRUCTURE.md#8-정해야-할-것)). 둘 다 **일반** 등급입니다. 장단점은 4-3과 같고, AI는 [전투 시스템 기획서 7장](COMBAT_DESIGN.md#7-적-ai)을 따릅니다.

## 6. 보스 몬스터

### 6-1. 보스의 조건 ✅

보스는 일반 몬스터의 시트(5-3)를 모두 채우고, 아래 네 항목을 더합니다. 보스도 장점과 단점을 함께 가집니다.

| 항목 | 뜻 | 예 |
|---|---|---|
| 높은 체력 | 일반 몬스터보다 크게 높은 HP. 한두 턴에 쓰러지지 않아 패턴을 보여 줄 시간을 만듦 | 일반 몬스터 HP의 몇 배 ❓ |
| 패배 조건 | 보스를 쓰러뜨리는 방법이나 플레이어가 지는 조건 | HP 0 / 특정 오브젝트 파괴 / N턴 버티기 ❓ |
| 패턴 | 보스가 반복하는 행동 순서. 플레이어가 읽고 대비할 수 있어야 함 | 2턴마다 범위 공격, 다음 턴 행동 예고 |
| 기믹 | 그 보스에게만 있는 특수 규칙 | HP 50%에 단계 전환, 졸개 소환, 기절 1회 면역 |

### 6-2. 보스 시트

| 항목 | 내용 |
|---|---|
| 등급 | 보스 |
| 컨셉 | 한 줄 |
| 장점 / 단점 | 단점은 공략의 실마리가 됨 |
| 높은 체력 | HP와 그 근거 |
| 패배 조건 | 보스 쪽, 아군 쪽 |
| 패턴 | 턴별 또는 조건별 행동표 |
| 기믹 | 특수 규칙과 화면에 알리는 방법 |
| 단계 | 단계가 있으면 전환 조건과 단계별 변화 |
| 등장 위치 | 막과 스테이지 |
| 보상 | 드랍 ❓ |

### 6-3. 기존 규칙과 부딪히는 점 ❓

보스를 만들기 전에 정해야 합니다.

| 기존 규칙 | 부딪히는 점 |
|---|---|
| 스테이지 승리 = 몬스터 전멸 ([게임 구조 기획서 2장](GAME_STRUCTURE.md#2-진행-구조)) | "오브젝트 파괴"나 "N턴 버티기" 같은 패배 조건을 쓰면 승리 조건에 예외가 생김 |
| 막별 적 강화(3막 최대 HP ×2) | 보스의 높은 체력에 강화를 또 곱할지 |
| 기절은 턴을 통째로 넘김 | 보스가 기절하면 패턴이 끊김. 면역이나 저항이 필요한지 |
| 적 AI는 공통 규칙 + 유닛별 규칙 | 패턴과 단계는 지금 AI 구조보다 복잡함 |
| 스킬 횟수는 막당 | 보스전 앞에서 스킬을 아끼게 되는지 |

## 7. 새 유닛 체크리스트

- [ ] 한 줄 컨셉이 있다. 캐릭터라면 정체와 사연이 있는 추상 컨셉이다.
- [ ] 캐릭터라면 스킬, 장점, 단점마다 근거 키워드가 있다.
- [ ] 장점과 단점이 모두 있고, 단점이 화면에서 보인다.
- [ ] 역할(캐릭터) 또는 등급과 역할(몬스터)이 정해졌다.
- [ ] 몬스터라면 던지는 질문과 대응 수단이 있다.
- [ ] 보스라면 높은 체력, 패배 조건, 패턴, 기믹을 모두 채웠다.
- [ ] 새 규칙이 필요하면 무엇인지 적고 Issue에 질문을 남겼다.
- [ ] 이름과 텍스트에 BG3 고유 명칭을 쓰지 않았다.
