> - 근거: 기획 논의, [전투 시스템 기획서](COMBAT_DESIGN.md) 5·6장, [능력치와 주사위 판정 기획서](ABILITY_SYSTEM.md) 4장, [로드맵](ROADMAP.md) M3 공격 타입, BG3 상태 지속 방식(참고)

## 2. 용어

| 용어 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| **동작** | 유닛이 자원을 써서 하는 모든 행위의 상위 개념. 기본 공격, 공용 동작, 고유 스킬을 포함. 행동·보조 행동·반응 중 하나를 소비 | 액션, 기술 |
| **기본 공격** | 모든 유닛이 가진 동작. 횟수 제한이 없고 행동을 소비 | |
| **공용 동작** | 모든 유닛이 쓰는 동작 (밀치기, 물약, 점프) | 기본 행동 |
| **스킬** | 직업 고유의 동작. 횟수 제한이 있음 | 기술, 특기 |
| **시전** | 동작을 쓰는 순간. 항상 즉시 일어남 | |
| **발동** | 동작의 효과가 대상에게 적용되는 순간. 즉발이면 시전과 같은 순간 | |
| **잔류 효과** | 시전이 남겨 발동을 기다리는 효과. 장판, 상태 이상, 예약 효과 | 객체, 오브젝트 |

- **행동과 동작의 구분**: 행동은 턴 자원(턴마다 1회 쓰는 실행 기회)이고, 동작은 그 자원을 써서 하는 행위입니다. 용어집의 행동 항목에 이 구분을 적었습니다.
- 기본 공격과 일반 스킬은 유형이 아니라 속성이 다릅니다. 횟수 무제한, 기회 공격(근접이면 가능, 원거리는 불가), 모든 유닛이 가진다는 점뿐입니다.

## 3. 동작을 정의하는 축

한 줄 목록으로 나누면 "곡사 장판", "직사 도트"처럼 겹치는 경우를 설명할 수 없어서, 서로 독립된 6개 축의 조합으로 정의합니다.

| 축 | 질문 | 값 |
|---|---|---|
| ① 조준 | 무엇을 겨누나 | 자신 / 유닛 / 칸(인접 칸으로 방향을 정하는 것 포함) / 환경 오브젝트 |
| ② 범위 | 얼마나 퍼지나 | 없음(1개) / 모양 프리셋 / 동작이 정한 모양. 기준점(자신·목표 칸)을 포함 (6장) |
| ③ 전달 | 어떻게 닿나 | 근접 / 직사 / 곡사 (5장) |
| ④ 효과 | 무엇이 남나 | 즉발 / 잔류 효과 (장판·상태·예약) |
| ⑤ 판정 | 무엇으로 겨루나 | 명중굴림(공격 굴림 대 AC) / 내성굴림(내성 굴림 대 DC) / 판정 없음 ([능력치 기획서 4장](ABILITY_SYSTEM.md#4-판정-규칙)) |
| ⑥ 비용 | 무엇을 쓰나 | 행동·보조 행동·반응·이동력과 횟수. 하나만 쓰거나 둘 이상을 **모두** 쓸 수 있음. 횟수 단위는 무제한 / 막당 / 전투마다 |
| ⑦ 속성 | 어떤 성질인가 | 없음 / 화염 / 물 (2026-11-09 첫 값). 반응은 장판 규칙이 정함 |

**⑦ 속성** ✅ (2026-11-09): 동작이 속성을 가질 수 있고 첫 값은 **화염**과 **물**입니다. 속성은 **장판과의 반응용 태그**이고, 유닛에 대한 효과(화상, 밀침 등)는 속성이 아니라 동작이 직접 정의합니다. 반응은 [전투 시스템 기획서 6-7](COMBAT_DESIGN.md#6-7-속성-기름-장판-넘어짐-산만함-2026-11-09)이 정합니다(화염은 기름 점화, 물은 기름·불 장판 삭제). "닿는다"는 동작의 목표 칸이며 명중 여부와 무관합니다. 물리/마법, 저항·취약·면역은 [로드맵 M3 6장 3번](ROADMAP.md#6-m3-전투-확장-기획)에서 따로 정합니다.

- **조준 흐름은 지금과 같습니다.** 동작 버튼을 고르고, 대상을 한 번 클릭해 미리보기를 보고, 한 번 더 클릭해 확정합니다 ([전투 기획서 9-4](COMBAT_DESIGN.md#9-4-동작-사용-흐름)). 바뀌는 것은 찍을 수 있는 대상의 종류가 늘어나는 것입니다. 이동과 점프는 이미 칸을 목표로 하고, 공격·효과 동작이 빈 칸을 목표로 하는 것이 새로 열립니다.
- **칸 조준은 M3 공격 타입 단계에서 도입했습니다** ✅ ([로드맵 M3 6장 2번](ROADMAP.md#6-m3-전투-확장-기획), [#466](https://github.com/minjunkim-dev/BGLike/issues/466)). 미리보기는 영향 범위를 칸 하이라이트로 보여줍니다.
- **지속 도트는 유형이 아닙니다.** 화상·독은 [상태 이상](COMBAT_DESIGN.md#6-상태-이상)이 맡고, 동작은 ④에서 "상태를 부여한다"만 고릅니다.
- **장판도 ④의 값입니다.** [지속 장판](COMBAT_DESIGN.md#6-5-지속-장판의-첫-두-종류)이 남기는 잔류 효과이고, 동작은 "칸에 장판을 만든다"만 정합니다.
- **선택 가능한 대상은 동작이 정합니다.** 기본 공격은 유닛(과 기존 상자·바위 같은 환경 오브젝트)이고, 동작마다 선택 가능한 대상의 종류를 지정합니다. 선택 가능 여부와 직사에서 경로를 막는지는 별개입니다 (5-1).
- **복합 비용**: 점프(이동력 + 보조 행동)가 이미 선례이고, 십자 베기(행동 + 보조 행동), 강철 돌진(보조 행동 + 이동력 1)도 자원 둘 이상을 모두 소비합니다. 모두 남아 있어야 쓸 수 있고, 버튼 호버에 비용 문구를 표시합니다. 여러 자원 중 하나를 고르는 동작(행동 또는 반응)과는 다릅니다.
- **패시브**: 자원과 횟수가 없고 조건이 맞으면 저절로 적용되는 동작입니다(팔랑크스, 괴력의 사내). 조건이 유지되는 동안 계속 적용되는 것은 상시 효과(4-1)입니다.

## 4. 시전과 발동

"3턴 뒤에 터지는 동작"이나 "조건이 맞으면 터지는 동작"도 쓴 순간에 자원을 쓰고 기억해 두는 것이므로 시전은 항상 즉시입니다. 달라지는 것은 효과가 나타나는 발동 시점입니다.

| 단계 | 언제 | 정해지는 것 |
|---|---|---|
| 시전 | 항상 즉시 | 자원 소비, 조준(대상·칸·방향), 명중굴림 동작의 명중굴림과 그 유리/불리, 내성굴림 동작의 DC 기록 |
| 발동 | 동작마다 다름 | 영향 범위 안의 대상, 내성굴림 동작의 대상별 내성굴림과 그 유리/불리, 효과 적용 |

### 4-1. 효과 ✅

- **즉발**: 시전과 같은 순간에 발동합니다 (기본 공격, 활 후려치기, 회전회오리).
- **잔류 효과를 남김**: 시전이 잔류 효과를 남기고, 효과의 발동 조건이 충족될 때 발동합니다.

| 잔류 효과 | 붙는 곳 | 발동 조건 |
|---|---|---|
| 장판 | 칸 | 진입 시, **이탈 시**(기름 장판), 대상 턴 시작 |
| 상태 이상 | 유닛 | 대상 턴 시작 (틱) |
| 예약 효과 | 칸 또는 유닛 | 후보: N턴 뒤, 조건 충족 (첫 사례가 나올 때 확정) |
| 버프 | 유닛 | 대상이 명중굴림을 할 때 (전투의 함성) |
| 방어막 | 유닛 | 대상이 피해를 받을 때, HP보다 먼저 흡수 (성스러운 장막) |
| 상시 효과 | 유닛 | 조건이 유지되는 동안 계속 (팔랑크스: 인접 아군이 있는 동안) |
| 약화 | 유닛 | 대상이 명중굴림·내성굴림을 할 때 (효시의 산만함: 둘 다 불리) |
| 소모 버프 | 유닛 | 기본 공격을 할 때 한 발씩 소모 (애기살) |
| 지정 불가 | 유닛 | 적이 대상을 고를 때 (은신) |

- 확정한 발동 조건은 **진입 시, 대상 턴 시작, 시전자 턴 시작, 피해를 받을 때, 명중굴림을 할 때, 조건이 유지되는 동안** 6개입니다. 앞의 셋은 기존 규칙이고(시전자 턴 시작은 기존 상태 이상·장판의 기간 감소에 쓰며 새 기본값은 4-5를 따릅니다), 뒤의 셋은 2026-10-30 전사 재디자인에서 추가했습니다. 2026-11-09 궁수 재디자인에서 **이탈 시**, **내성굴림을 할 때**, **기본 공격을 할 때**, **지정될 때**가 추가됐습니다.
- **이탈 시**: 유닛이 칸을 **떠나기 직전**에 발동합니다. 기회 공격보다 **먼저** 처리하고, 이탈 굴림에 실패하면 이동이 취소되어 칸을 떠나지 않으므로 기회 공격도 일어나지 않습니다. 걷기, 점프, 도약, 반응 이동(반사신경)은 해당하고 밀치기·끌기 같은 **강제 이동으로 떠나는 것은 해당하지 않습니다**(강제 이동으로 들어가는 것은 진입으로 처리). 같은 대상은 **기름 장판 전체에 대해**(칸이 달라도) 이탈·진입 시도를 다음 자기 실제 턴 시작 전까지 합쳐 1회만 합니다. 기존 불·독 장판의 진입 기록은 장판 하나마다 셉니다.
- 잔류 효과는 시전자와 독립된 개체입니다. 시전자가 전투 불능이 되어도 유지하는 것이 기본값입니다 (8장).

### 4-2. 명중굴림과 내성굴림 ✅

- **명중굴림**은 시전 때 공격자가 한 번 굴려 대상의 AC와 비교합니다. 유리/불리도 시전 때 정해집니다.
- **내성굴림**은 발동 때 대상이 굴립니다. 비교하는 DC는 **시전 때 기록**하며, 장판 같은 잔류 효과는 발동 때마다 그 기록값(또는 효과 정의의 고정값)과 대상의 내성 굴림을 비교합니다. 시전자는 굴리지 않습니다.
- 대상마다 내성굴림을 따로 하므로 범위 효과의 공통 공격 굴림은 없습니다 ([능력치 기획서 4-4](ABILITY_SYSTEM.md#4-4-한-동작은-판정-하나-)).
- 발동 때 DC를 새로 정하는 동작은 해당 동작의 기획서에 명시한 경우에만 허용합니다. 데이터 옵션은 그런 동작이 생길 때 미리보기·로그·저장 처리와 함께 추가합니다.
- 기존 독 중첩 제거의 고정 DC가 이 규칙의 첫 사례이고, **독안개**(시전자가 있는 독, [#461](https://github.com/minjunkim-dev/BGLike/issues/461)에서 구현)는 **부여** 판정의 DC를 시전 때 기록하는 방식의 첫 사례입니다. 독안개 장판은 그 DC를 보존합니다. 독안개의 독 **제거** DC는 기존 독 장판처럼 고정 4입니다 ([능력치 기획서 8장](ABILITY_SYSTEM.md#8-현재-동작에-적용하는-임시-규칙), [전투 기획서 6-6](COMBAT_DESIGN.md#6-6-독안개-장판)).

### 4-3. 대상 명단 ✅

대상은 잔류 효과가 붙는 곳이 정합니다. 별도 옵션은 두지 않습니다.

| 붙는 곳 | 대상 |
|---|---|
| 칸 | 발동 때 그 칸의 범위 안에 있는 유닛 |
| 유닛 | 시전 때 지정한 그 유닛. 이동해도 따라감. 그 유닛이 전투 불능이 되면 효과도 사라짐 |

### 4-4. 시전 즉시 범위 안 유닛 ✅

칸에 붙는 잔류 효과는 시전 순간 범위 안에 있던 유닛에게도 발동하는 것이 기본값입니다. 동작마다 제외할 수 있습니다 (8장).

### 4-5. 기간 시계 ✅

기간 시계는 시전자가 아니라 **잔류 효과가 가집니다.** 줄어드는 시점은 효과의 속성이며, 기본값은 **시전자의 턴 시작**입니다 ✅ (2026-10-30 기획자 결정: 디폴트는 항상 시전자 기준). 참고로 BG3는 대상 턴 시작이 기본이지만 이 게임은 시전자 기준을 씁니다.

| 붙는 곳 | 기본 시계 | 이유 |
|---|---|---|
| 유닛 | **시전자의 턴 시작** | 한 번의 시전으로 여러 대상에 붙은 효과가 모두 같은 시점에 끝남(전투의 함성). 시전자와 대상이 같으면 대상의 턴 시작과 같음(성스러운 장막) |
| 칸 | **시전 시점의 시전자 이니셔티브 위치**의 턴 시작 | 대상이 없음. 라운드 시작이면 이니셔티브가 마지막인 유닛의 효과가 바로 줄어 손해를 봄. 이 방식은 어느 순서에서 시전해도 정확히 N라운드 |

- 칸에 붙는 효과는 시전자가 전투 불능이 되어도 기록한 위치의 턴 시작마다 줄어듭니다. 전투 불능 유닛의 위치는 보이지 않는 시계 슬롯으로 보관합니다.
- 유닛에 붙은 효과도 시전자가 전투 불능이 되어도 유지하고, 쓰러진 시전자의 이니셔티브 위치를 시계 슬롯으로 보관해 계속 줄입니다(전투의 함성). 8-1의 기존 상태 이상·장판은 시전자 전투 불능 시 해제를 유지합니다.
- 동작은 이 시계를 바꿀 수 있고, 바꾸는 동작은 기획서에 명시합니다. 시계가 있는 효과의 기본 분류는 아래 4종이고(지속형·이번 턴형·조건형·전투형), 대상 기준이나 라운드 단위 시계는 필요해질 때 예외로 명시합니다.

**소멸 시점의 분류** (2026-11-02 기획자 결정)

시계가 있는 효과는 아래 분류 중 하나를 고르고, 기본은 지속형입니다. 턴 시작·종료 처리 순서는 [전투 시스템 기획서 3-5](COMBAT_DESIGN.md#3-5-턴-시작종료-처리-순서)를 따릅니다.

| 분류 | 의미 | 소멸 시점 | 예 |
|---|---|---|---|
| **지속형** (기본) | 상대 턴 동안 이어지고 자기 다음 턴이 올 때까지 | 시전자 턴 시작: 그 시작의 틱을 처리한 뒤 기간 −1, 0이면 소멸 | 성스러운 장막, 전투의 함성, 장판, 화상·독, 기절 |
| **이번 턴형** | 이번 턴 안에서만 | 시전자 턴 종료(묶음 확정)의 첫 처리 | 물러서며 쏘기 |
| **조건형** | 조건이 유지되는 동안 | 시계 없음, 조건이 사라지면 해제 | 팔랑크스 |
| **전투형** | 전투가 끝날 때까지 | 전투 종료 | 애기살 급조의 남은 발수, 과부하 |

- **즉발 자원 변경**(괴력의 사내의 이동력 0, 몬스터의 자원 제거 스킬)은 효과를 남기지 않으므로 분류 밖입니다. 기간 시계가 없고 대상의 자원 회복 시점(묶음 확정)에 복구됩니다.
- 대상 기준 시계가 필요한 효과는 그 동작 기획서에 예외로 명시합니다. 지금 사례는 **넘어짐**(기름 장판의 미끌거림)이며, **일어서면(최대 이동력의 절반) 또는 대상의 실제 턴 시작에 자동 해제**됩니다. 시전자와 무관합니다([궁수 문서](characters/archer.md), [전투 시스템 기획서 6-7](COMBAT_DESIGN.md#6-7-속성-기름-장판-넘어짐-산만함-2026-11-09)).

`개발 결정`([#423](https://github.com/minjunkim-dev/BGLike/issues/423), [#356](https://github.com/minjunkim-dev/BGLike/issues/356), 구현 [#425](https://github.com/minjunkim-dev/BGLike/pull/425)): 시계 슬롯은 쓰러진 시전자의 순서 자리를 `[시전자, 바로 뒤 유닛, 이번 순환에서 지났는지]`로 보관합니다. 기획자가 바꿀 수 있습니다.

- 바로 뒤 유닛의 턴 시작 직전에 시전자의 효과를 줄입니다. 시전자가 이번 순환에서 턴을 시작한 뒤 쓰러졌고 그 자리에 대응하는 바로 뒤 유닛의 턴 시작이 아직이면, 그 시작 한 번은 건너뜁니다. 시전자가 순서의 끝이면 다음 라운드 첫 유닛의 시작이 여기에 해당합니다. 그 유닛이 쓰러지면 그다음 유닛으로 옮기고, 시전자의 효과가 모두 끝나면 지웁니다. 시전자 한 명에 슬롯 하나입니다.
- 소환 유닛이 쓰러진 자리와 바로 뒤 유닛 사이에 들어오면 기준을 소환 유닛으로 옮기고, 생성 라운드의 소환 유닛은 이번 순환에서 시작하지 않는 유닛으로 봅니다. 같은 묶음에서 바로 뒤 유닛을 먼저 조작한 뒤 시전자가 자기 턴 전에 쓰러져도 시전자의 이번 순환 몫을 줄입니다. 이번 순환 몫을 아직 줄이지 않았는데 바로 뒤 유닛의 다음 시작이 다음 순환이면(이미 시작했거나 생성 라운드 소환 유닛) 시전자나 기준 유닛이 쓰러질 때 바로 한 번 줄입니다([#427](https://github.com/minjunkim-dev/BGLike/issues/427)).
- 슬롯은 턴 순서 데이터(`turns.gd`)와 따로 `actions.gd`에 둡니다. 전투 불능 초상은 지금처럼 바로 빠지고 [턴 묶음](COMBAT_DESIGN.md#3-2-턴-묶음) 처리도 그대로입니다.
- 저장 본문의 `clock_slots`에 유닛 목록 번호로 남깁니다(이어하기 형식 4, [ADR 0003](adr/0003-save-files.md)). 이어하기는 시전자가 쓰러져 턴 순서에 없고 기준 유닛이 순서에 있는 슬롯만 받습니다.
- 지금 슬롯을 쓰는 효과는 전투의 함성뿐입니다. 성스러운 장막은 시전자 자신에게 붙어 시전자와 함께 사라집니다.
- 시전자가 쓰러져도 남는 새 칸 효과가 생기면 같은 슬롯을 재사용합니다. 8-1의 불·독 장판은 지금처럼 시전자와 함께 사라지고 슬롯을 쓰지 않습니다. 시전자가 살아 있으면 시전자 턴 시작에 줄이고, 쓰러지면 슬롯이 그 자리에서 순환마다 한 번 줄입니다. 슬롯 모양과 저장 키는 그대로 두고, 슬롯을 남기고 줄이는 대상에 그 시전자의 새 칸 효과를 더합니다. 새 칸 효과는 시전자 전투 불능 때 지우지 않습니다.
- 칸 효과를 도입하는 M3 공격 타입 단계의 세 가지는 첫 사례인 독안개([#461](https://github.com/minjunkim-dev/BGLike/issues/461)에서 구현, [#305 기획자 답](https://github.com/minjunkim-dev/BGLike/issues/305#issuecomment-6581920839))로 정했습니다. ① 저장: 장판은 기존 기록(시전자 번호, 남은 기간, 진입 기록)에 DC를 더하고, 시전자가 쓰러져도 번호를 유지하며 사후에는 시계 슬롯이 줄입니다. ② 슬롯이 여럿이면 먼저 시전한 장판부터 줄입니다. ③ 턴 묶음·라운드 경계로 초상 순서가 바뀌어도 시전 시점의 이니셔티브 자리를 고정해, 칸 효과는 어떤 상황에서도 정확히 시전자의 N번째 순서 시작에 사라집니다.

## 5. 전달 방식: 근접, 직사, 곡사

전달 방식은 무기·스킬의 **공격 거리 유형**(근접/원거리, 사거리·기회 공격·인접 시 불리에 쓰는 데이터, [능력치 기획서 2장 용어](ABILITY_SYSTEM.md#용어))과 별개의 축입니다. 거리 유형은 능력치를 정하지 않으며, 전달 방식은 경로의 차단을 정합니다.

| 전달 | 경로 | 막는 것 | 맞는 곳 |
|---|---|---|---|
| 근접 | 인접 | 해당 없음 | 인접 칸 |
| 직사 | 직선 | 경로 위의 차단 대상 | 경로의 첫 차단 대상, 없으면 목표 |
| 곡사 | 포물선 | 경로는 차단되지 않음 | 목표 칸 |

- **원거리 동작의 기본값은 곡사입니다** ✅. 현재의 궁수 기본 공격, 풋내기 궁수 등 모든 원거리 동작은 곡사로 봅니다. 현재 동작(차단 없음)과 같아서 기존 스테이지와 밸런스를 바꾸지 않습니다. 직사로 지정하는 동작은 그 동작을 기획할 때 정합니다.

### 5-1. 직사: 선택 가능 대상과 차단 대상 ✅

직사 동작은 두 집합을 따로 가집니다.

| 집합 | 뜻 | 원소 |
|---|---|---|
| 선택 가능 대상 | 이 동작의 목표로 고를 수 있는 것 | 적 유닛 / 아군 유닛 / 지형 / 환경요소 |
| 차단 대상 | 경로에 있으면 동작을 막는 것 | 적 유닛 / 아군 유닛 / 지형 / 환경요소 |

- 목표는 선택 가능 대상의 유형이기만 하면 고를 수 있습니다.
- 경로에 차단 대상이 있으면 **그 차단 대상이 맞습니다.** 따라서 미리보기는 실제로 맞는 대상을 보여줘야 합니다.
- 지형을 고를 수 있는지는 선택 가능 대상에 지형이 있는지, 지형이 경로를 막는지는 차단 대상에 지형이 있는지에 따라 다릅니다. 둘은 서로 독립입니다.
- **기본 차단 대상은 아군을 제외한 모든 것**입니다. 아군은 통과합니다.
- 아군도 막는 동작은 차단 집합에 아군을 추가합니다. 관통하는 동작은 해당 원소를 뺍니다.

### 5-2. 곡사의 목표 칸 ✅

곡사와 칸 조준 동작이 목표로 고를 수 있는 칸의 기본 조건은 [장판 규칙](COMBAT_DESIGN.md#6-5-지속-장판의-첫-두-종류)과 같습니다.

- 사거리 안이어야 합니다.
- 맵 안의 막히지 않은 바닥이면 고를 수 있습니다. 높이와 점유 여부는 상관없습니다.
- 맵 밖, 낭떠러지, 막힌 칸은 고를 수 없습니다. 여기서 막힌 칸은 벽·집·나무 같은 장벽입니다. 박스·바위 칸은 고를 수 있고, 화염 속성 동작은 나무 칸도 고를 수 있습니다(구현 전). 요소별 표는 [환경요소 2-2](ENVIRONMENT_ELEMENTS.md#2-2-공격시선파괴)입니다.

### 5-3. 불리 ✅

원거리 공격의 불리 조건(인접 칸에 기절하지 않은 적, [능력치 기획서 4-7](ABILITY_SYSTEM.md#4-7-유리--불리-))은 전달 방식과 무관하게 직사와 곡사 모두에 적용합니다.

### 5-4. 도입 시기

직사의 차단 규칙은 [로드맵 M3 6장](ROADMAP.md#6-m3-전투-확장-기획)의 맵 기획(시야·엄폐) 다음, 공격 타입 단계에서 도입합니다. 그때까지 시야·엄폐는 없고 [게임 구조 6-2](GAME_STRUCTURE.md#6-2-거리와-인접-)를 따릅니다.

## 6. 범위 모양

범위 모양은 동작마다 자유롭게 정합니다. 자주 쓰이는 형태는 프리셋으로 제공해 동작마다 새로 정의하지 않게 합니다.

| 구성 | 내용 |
|---|---|
| 기준점 | 자신 / 목표 칸 |
| 방향 | 모양마다 정함 ✅. 직선·부채꼴의 방향 규칙은 도입 시점의 해당 동작 기획에서 정함 |
| 프리셋 | **반경, 직선, 부채꼴, 정사각형** 4개 ✅. 더 필요하면 사례가 생길 때 추가 |
| 높이·벽 | 기본값은 현재 규칙. 중심 바닥과 높이 차이 1 이하인 유효 바닥에 적용하고, 중간 칸의 높이·벽은 보지 않음 ([전투 기획서 6-4](COMBAT_DESIGN.md#6-4-범위-스킬의-첫-모양과-높이)). 동작마다 다르게 정할 수 있음 |
| 현재 | 반경(회전회오리, 폭죽 화살, 기름 장판)과 부채꼴 반달 5칸(전사 휩쓸기), 띠(궁수 효시, 구현 전)가 있음 |

- **부채꼴 첫 사례 (휩쓸기)**: 기준점은 자신입니다. 방향은 인접 4칸(상하좌우) 중 하나를 골라 정하고(적이 없는 칸도 가능), 모양은 정면 기준 앞 3칸과 양옆 2칸의 **반달 5칸**입니다. 영향 칸은 기준점 바닥과 높이 차 1 이하이고, 대상은 시계방향으로 한 명씩 판정합니다. 직선과 더 큰 부채꼴은 후속입니다.
- **띠 첫 사례 (효시)** ✅: 기준점은 자신이고 방향은 **상하좌우 4방향** 중 하나를 고릅니다. 모양은 고른 방향의 **모든 칸**(자신의 바로 앞 칸부터 맵 끝까지)과 그 칸들의 **양옆 칸**으로 이뤄진 세 줄 폭의 띠입니다. 자신이 서 있는 줄의 양옆 칸은 제외합니다. 높이·벽은 보지 않는 기본값을 따릅니다. 대상은 영향 칸의 적입니다. 일반 직선(1줄)과 폭이 다른 띠는 후속입니다.
- **곡사 반경 1 칸 조준** ✅: 폭죽 화살과 기름병은 곡사로 목표 칸을 정하고 반경 1(중심과 상하좌우 5칸)이 영향 범위입니다. 목표 칸은 [5-2](#5-2-곡사의-목표-칸-)의 조건을 따르며, 사거리 0(자기 발밑)을 허용하는지는 동작이 정합니다(폭죽 화살은 허용).

## 8. 기본값과 예외

기획 문서는 "동작마다 다르게 할 수 있다"고 열어두고, 구현은 그 예외를 쓰는 동작이 생길 때 만듭니다. 예외는 해당 동작의 기획서에 명시한 경우에만 허용합니다.

| 항목 | 새 기본값 | 예외 |
|---|---|---|
| 전달 | 곡사 (원거리), 근접 | 직사 지정 |
| 직사 선택 가능 대상 | 동작이 정함 | — |
| 직사 차단 대상 | 아군 제외 전부 | 동작마다 집합 지정 |
| 판정 기준 | 명중굴림은 시전 때 굴림, DC는 시전 때 기록 | 발동 때 새로 정함 (동작 기획서에 명시) |
| 시전자 전투 불능 시 | 잔류 효과 유지 | 소멸 |
| 시전 즉시 범위 안 유닛 | 발동함 | 제외. 불·독 장판은 8-1, 기름 장판은 이동할 때만 발동하므로 시전 즉시 발동하지 않음 |
| 기간 시계 | 유닛: **시전자 턴 시작** (2026-10-30) / 칸: 시전 시점의 시전자 순서 자리 | 동작마다 지정 |
| 범위 모양 | 프리셋 | 동작이 직접 정의 |
| 범위 높이·벽 | 현재 규칙 | 동작마다 지정 |

### 8-1. 이미 확정한 규칙은 예외로 유지

새 기본값과 달라도 기존 논의대로 유지합니다 ([#138](https://github.com/minjunkim-dev/BGLike/issues/138), [#186](https://github.com/minjunkim-dev/BGLike/issues/186), [전투 기획서 6장](COMBAT_DESIGN.md#6-상태-이상)).

| 기존 동작 | 유지하는 규칙 (새 기본값과 다른 점) |
|---|---|
| 불 장판, 독 장판 | 시전자 전투 불능 시 즉시 소멸. 생성 당시 점유 유닛에는 부여하지 않음. 기간은 시전자 턴 시작에 줄어듦 |
| 기절, 화상, 독 | 시전자 전투 불능 시 즉시 해제. 기간은 시전자 턴 시작에 줄어듦 |
| 독안개의 독 중첩 | 기간이 없음(줄지 않음). 시전자 전투 불능 시 해제하지 않음. 독 제거 굴림으로만 사라짐. 기존 독과 다른 새 동작의 예외 |

기존 규칙을 새 기본값으로 이관할지는 이 문서의 범위가 아닙니다. 독안개 장판은 새 기본값(시전 즉시 발동, 사후 유지, 칸 기본 시계)을 따르고 기존 독 장판(고정 DC 4, 시전자와 함께 소멸)은 예외를 유지합니다. 같은 독을 거는 두 장판이 다르게 동작하므로 이관 여부는 9장 7번에서 다룹니다.
