## 3. 시작 위치

개발에 그대로 넘길 수 있는 좌표입니다.

### 3-1. 좌표 규칙 ✅

> 2026-10-18 격자를 높이 있는 사각 타일로 바꿨습니다([게임 구조 기획서 6장](../GAME_STRUCTURE.md#6-사각-높이-격자)). 전환 때 아래 좌표와 몬스터 구성을 보존하고 높이0으로 옮겼습니다. 사각 논리 격자는 #163에서, 높이 상호작용은 #164에서 구현했습니다. #170은 화면을 아이소메트릭 마름모로 교정했습니다. #189는 실제 첫 전투에 대표 배치를 추가했습니다. #195는 그 배치와 기존 스폰을 보존하면서9개 맵에 실제 도트 지형·계단·고지를 추가합니다. 현재 규격과 #347의 상자·바위 재배치는 [맵 제작 기준](../TERRAIN_MAPS.md)을 따릅니다. 아래 지도는 화면 투영과 별개인 논리 좌표와 거리입니다.

- 좌표는 `(열, 행)`이며, 코드의 `Vector2i(열, 행)`과 같습니다 (`scenes/combat/grid.gd`, 스테이지 데이터의 `start_cell`).
- 맵은 10열 × 10행, 열과 행은 0~9입니다. 모든 행의 열이 같은 위치에 놓인 사각 격자입니다. 인접과 걷기는 상하좌우 4방향입니다. 거리는 열 차이와 행 차이의 절댓값을 더합니다.
- 맵을 좌우로 나눠 **0~4열은 아군, 5~9열은 적** 쪽입니다 (2026-10-15). 아군은 오른쪽을 보고 옆모습으로 시작합니다. 사각 전환 후에도 기존 좌표와 방향을 유지합니다.
- 아군 시작 칸은 **전사 (1, 4), 궁수 (0, 5)**입니다 (2026-10-15). 전사가 궁수보다 오른쪽(앞)에 섭니다. 모든 스테이지에 이 좌표와 오른쪽을 보는 방향을 적용했습니다.

## 4. 지형 데이터와 현재 배치

2026-10-21의 [#137 위임 명세](https://github.com/minjunkim-dev/BGLike/issues/137#issuecomment-6301869258)에 따라 #188은 실제1막1스테이지의(2,1)에 내구도6 나무 상자1개를 배치합니다. #189는 바위(4,1), 물(5,1), 낭떠러지(6,1), 높이(3,0)=1/(4,0)=2/(5,0)=2를 추가합니다. 2026-10-25 사용자 승인 [#347](https://github.com/minjunkim-dev/BGLike/issues/347)에서 첫 전투 상자를(3,4), 바위를(6,6)으로 옮기고9맵의 접근로 배치를 갱신했습니다. 물·높이·낭떠러지는 그대로입니다. `CombatStage.crate_cells`와`rock_cells`의 초기 위치에서 전투마다 새 물체 상태를 만듭니다. 상자를 부수거나 바위가 이동·소멸하면 비운칸을 사용합니다. 막 재시작은 상자 HP6/바위 초기위치/대표지형을 복원합니다. 아군/적 시작 위치·적수·보상은 유지합니다. 시험 전투 자원의 기본 배치는 비어 있습니다. 실제9개 전투의 현재 물체·지형은 #195/#347의 [맵 제작 기준](../TERRAIN_MAPS.md)과 스테이지 자원을 따릅니다. 규칙은 [게임 구조6-8](../GAME_STRUCTURE.md#6-8-환경-오브젝트와-나무-상자)을 따릅니다.

`CombatStage.heights`는 칸별 높이다. 생략한 칸의 높이는0이다. `pits`는 바닥이 없는 칸이다. `blocked_cells`는 바닥이 있지만 걷기·점프 통과·착지·소환·강제 이동을 막는 칸이다. 기본값은 모두 비어 있다. 막힌 칸은 실제 무너진 벽 PNG로 표시한다. `scenery`는 나무·무너진 벽·집의 기준 칸과 자산을 담는다. `get_blocked_cells()`가 장식 footprint와 명시한 막힌 칸을 합친다. 나무·무너진 벽은1×1, 집은2×2칸이다. `path_cells`와`stone_cells`는 바닥 재질만 지정한다.

`CombatStage.water_cells`는 물 바닥의 칸 목록이다. 기본값은 비어 있다. #178에서 실제 전투 격자와 청록색 표시로 전달한다. 물의 화상 해제·화상 부여 거부 규칙은 [전투 기획서6장](../COMBAT_DESIGN.md#6-상태-이상)을 따른다. #189는 실제 첫 전투에 물(5,1)을 배치한다. #195는9개 전투의 실제 물길을 배치한다. 기본 시험 자원의 물 배치는 비어 있다.

[Issue #166의 구현 결정](https://github.com/minjunkim-dev/BGLike/issues/166#issuecomment-6293059168)에 따라 판정용 필드를 연결했다. #189는 첫 전투에 위 대표 높이·낭떠러지 배치를 추가한다. 현재9개 맵의 배치는 [#195 제작 기준](../TERRAIN_MAPS.md)과 실제 스테이지 자원으로 확정한다. 사용자 선택 위임으로 채택한 첫 배치다.
