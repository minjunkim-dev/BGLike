## 3. 시작 위치

개발에 그대로 넘길 수 있는 좌표입니다.

### 3-1. 좌표 규칙 ✅

> 2026-10-18 격자를 높이 있는 사각 타일로 바꿨습니다([게임 구조 기획서 6장](../GAME_STRUCTURE.md#6-사각-높이-격자)). 전환할 때 아래 좌표와 몬스터 구성은 그대로 두고 모든 칸의 높이를 0으로 둡니다. 사각 논리 격자는 #163에서, 높이 상호작용은 #164에서 구현했습니다. #170은 화면을 아이소메트릭 마름모로 교정합니다. 아래 지도는 화면 투영과 별개인 논리 좌표와 거리입니다. 새 높이 배치는 후속 기획입니다.

- 좌표는 `(열, 행)`이며, 코드의 `Vector2i(열, 행)`과 같습니다 (`scenes/combat/grid.gd`, 스테이지 데이터의 `start_cell`).
- 맵은 10열 × 10행, 열과 행은 0~9입니다. 모든 행의 열이 같은 위치에 놓인 사각 격자입니다. 인접과 걷기는 상하좌우 4방향입니다. 거리는 열 차이와 행 차이의 절댓값을 더합니다.
- 맵을 좌우로 나눠 **0~4열은 아군, 5~9열은 적** 쪽입니다 (2026-10-15). 아군은 오른쪽을 보고 옆모습으로 시작합니다. 사각 전환 후에도 기존 좌표와 방향을 유지합니다.
- 아군 시작 칸은 **전사 (1, 4), 궁수 (0, 5)**입니다 (2026-10-15). 전사가 궁수보다 오른쪽(앞)에 섭니다. 모든 스테이지에 이 좌표와 오른쪽을 보는 방향을 적용했습니다.

## 4. 정해야 할 것 ❓

2026-10-21의 [#137 위임 명세](https://github.com/minjunkim-dev/BGLike/issues/137#issuecomment-6301869258)에 따라 #188은 실제1막1스테이지의(2,1)에 내구도6 나무 상자1개를 배치합니다. `CombatStage.crate_cells`의 초기 위치에서 전투마다 새 상태를 만듭니다. 상자를 부수면 그 칸이 열리고, 막을 다시 시작하면 내구도6으로 복원합니다. 아군/적 시작 위치·적수·보상은 유지합니다. 시험 전투 자원과 나머지8전투의 상자 배치는 비어 있습니다. 바위/대표 지형 배치는 #189에서 이어서 연결합니다. 규칙은 [게임 구조6-8](../GAME_STRUCTURE.md#6-8-환경-오브젝트와-나무-상자)을 따릅니다.

`CombatStage.heights`는 칸별 높이다. 생략한 칸의 높이는0이다. `pits`는 바닥이 없는 칸이다. `blocked_cells`는 바닥이 있지만 걷기·점프 통과·착지·소환·강제 이동을 막는 칸이다. 기본값은 모두 비어 있다. 막힌 칸은 임시 X 표시로 구분한다. 이 표시는 최종 벽·장애물 자산이 아니다.

`CombatStage.water_cells`는 물 바닥의 칸 목록이다. 기본값은 비어 있다. #178에서 실제 전투 격자와 청록색 표시로 전달한다. 물의 화상 해제·화상 부여 거부 규칙은 [전투 기획서6장](../COMBAT_DESIGN.md#6-상태-이상)을 따른다. 기존9개 스테이지에는 물 칸을 추가하지 않았다. 실제 배치는 후속 맵 기획이다.

[Issue #166의 구현 결정](https://github.com/minjunkim-dev/BGLike/issues/166#issuecomment-6293059168)에 따라 판정용 필드를 연결했다. 위9개 스테이지의 실제 높이·낭떠러지·장애물 배치는 추가하지 않았다. 새 배치는 후속 맵 기획에서 정한다.
