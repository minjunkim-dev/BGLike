| 스테이지 3 | 고철로봇 1마리 대 아군 2명. 고철로봇은 보스 항목(높은 체력, 패턴, 기믹)을 씀 |

## 3. 시작 위치

개발에 그대로 넘길 수 있는 좌표입니다.

### 3-1. 좌표 규칙 ✅

- 좌표는 `(열, 행)`이며, 코드의 `Vector2i(열, 행)`과 같습니다 (`scenes/combat/hex_grid.gd`, 스테이지 데이터의 `start_cell`).
- 맵은 10열 × 10행, 열과 행은 0~9입니다. 뾰족한 위 헥사이고 **홀수 행이 오른쪽으로 반 칸 밀려** 있습니다.
- 맵을 좌우로 나눠 **0~4열은 아군, 5~9열은 적** 쪽입니다 (2026-10-15). 아군이 오른쪽을 보고 옆모습으로 시작하고, 헥사가 일직선으로 이어지는 가로 방향으로 나아가는 느낌을 주기 위해서입니다.
- 아군 시작 칸은 **전사 (1, 4), 궁수 (0, 5)**입니다 (2026-10-15). 전사가 궁수보다 오른쪽(앞)에 섭니다. 지금 구현은 전사 (4, 9), 궁수 (5, 9)입니다.

### 3-2. 스테이지별 좌표 ✅

| 스테이지 | 적 시작 칸 |
|---|---|
| 1막 스테이지 1 | 새끼 거미 (7, 2), (8, 4), (7, 6), (8, 8) |
| 1막 스테이지 2 | 풋내기 야만인 (7, 4) |
| 1막 스테이지 3 | 고철로봇-1000 (8, 4) |
| 2막 스테이지 1 | 새끼 거미 (6, 1), (7, 3), (7, 6), (6, 8) · 엄마 거미 (9, 4) |
| 2막 스테이지 2 | 풋내기 야만인 (6, 3) · 풋내기 궁수 (8, 6) |
| 2막 스테이지 3 | 고철로봇-2000 (8, 4) |
| 3막 스테이지 1 | 새끼 거미 (7, 2), (7, 4), (7, 7) · 엄마 거미 (9, 2), (9, 7) |
| 3막 스테이지 2 | 풋내기 야만인 (6, 2), (6, 7) · 풋내기 궁수 (9, 4) |
| 3막 스테이지 3 | 고철로봇-3000 (8, 4) |

- 거미는 넓게 퍼뜨리고 엄마 거미는 뒤(9열)에 두어, 새끼를 뚫고 가야 엄마에게 닿게 했습니다.
- 풋내기 스테이지는 야만인이 앞(6~7열), 궁수가 뒤(8~9열)에 섭니다.
- 고철로봇은 적 쪽 가운데 (8, 4)이고, 아군 전사와 같은 4행에 일직선으로 섭니다. 아군이 움직이기 전 거리는 7입니다. 2000·3000의 만능팔은 이동(4칸) 뒤 3칸 안이어야 쓰므로, 첫 턴부터 전사를 끌어올 수 있습니다.
