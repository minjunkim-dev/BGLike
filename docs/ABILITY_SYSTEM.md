## 2. 현재 구현 (코드 기준)

### 2-1. 주사위를 굴리는 곳

모든 굴림은 `CombatDice`([dice.gd](../scenes/combat/dice.gd))를 지납니다. 테스트는 같은 인터페이스에 정해진 값을 주는 어댑터를 씁니다.

| 종류 | 굴림 | 비교 대상 |
|---|---|---|
| 이니셔티브 | `d20 + 민첩` | 높은 순. 동점이면 민첩이 높은 쪽, 그다음 아군 |
| 명중 판정 | `d20 + 공격 보너스` | 대상의 **AC**. 20은 치명타(자동 명중), 1은 자동 실패. 유리/불리 적용 |
| 내성 굴림 | `d20 + 능력치 보정값` | 공격자의 **내성 DC**. 1과 20도 합계로만 판단 |
| 대결 | 양쪽 `d20 + 보정값` | 상대 합계. 동점이면 방어 쪽 승 |
| 피해 | 무기별 `1dN + 피해 보정` | 치명타면 피해 주사위를 두 번 굴림 |
| 표식 추가 피해 | `+1d6` | 치명타면 두 번 |
| 회복 | 숨 고르기 `1d10+1`, 물약 `2d4+2` | |
| 무작위 선택 | 소환 위치, 끌어온 위치, 전리품 추첨, 아이템 수치, 추가 드랍 | |

- **AC**는 방어자가 가진 고정값이고, 공격자가 그 값을 넘기려고 굴립니다.
- **내성 DC**는 공격자가 가진 고정값이고, 방어자가 그 값을 넘기려고 굴립니다.
- 내성 굴림은 지금 흘려내기(민첩)와 충격 화살의 기절(정신) 두 곳에서 씁니다.

### 2-2. 능력치와 파생 수치

| 능력치 | 전사 / 궁수 | 실제로 쓰이는 곳 |
|---|---|---|
| 힘 | +3 / 0 | 밀치기·만능팔 대결, 전사의 공격 능력치 |
| 민첩 | +1 / +3 | 이니셔티브, 흘려내기, 대결 방어측, 궁수의 공격 능력치 |
| 건강 | +2 / +1 | UI 표시만 있고 판정과 HP에는 쓰이지 않음 |
| 정신 | −1 / +1 | 충격 화살의 기절 내성 |

능력치가 아닌 상수도 있습니다. 모두 주사위가 아닙니다.

| 항목 | 현재 값 | 비고 |
|---|---|---|
| 공격 보너스 | 5 (+ 장비) | 문서상 `숙련 2 + 공격 능력치 3`이지만 코드는 상수 |
| 내성 DC | 13 (적은 10~13) | 문서상 `8 + 숙련 2 + 공격 능력치 3`이지만 코드는 상수 |
| 피해 보정 | 전사 3, 궁수 1 (+ 장비) | 궁수는 플레이 테스트로 의도적으로 낮춤 |
| AC | 전사 16, 궁수 14 (+ 장비), 적 6~16 | 능력치와 무관한 상수 |
| HP | 전사 12, 궁수 14 (+ 장비) | |
| 이동력 | 6 (적은 4) | |
| 숙련 보너스 | +2 고정 | 레벨이 없어 상수일 뿐이며 코드에는 없음 |

기절은 지금 유일한 상태 이상입니다. 걸리면 다음 순서를 건너뛰고 자동으로 풀립니다. 벗어나기 판정은 없습니다.

## 3. 정해진 것 ✅

### 3-1. 방향

- 능력치, 공격, 피해 시스템은 **BG3(D&D 5e SRD) 방식을 그대로 가져옵니다.** 나중에 경량화하거나 변형합니다.
- **숙련 시스템은 뺍니다.** 숙련 보너스가 들어가던 곳은 능력치 보정값만 남깁니다.

숙련을 빼면 명중과 내성 DC가 일괄 2 낮아집니다(전사 공격 보너스 5 → 3, 내성 DC 13 → 11). 현재 밸런스를 유지하려면 AC와 내성 DC 상수도 같이 2씩 낮추면 됩니다. ❓ 실제 값은 구현 때 정합니다.

### 3-2. 능력치 5종과 정체성

BG3의 6종에서 **매력을 제외**합니다. 매력으로 시전하던 직업은 지능이나 지혜 쪽으로 옮깁니다.

| 능력치 | 정체성 |
|---|---|
| 힘 | 근접 (물리 위력) |
| 민첩 | 원거리 (정확·회피·속도) |
| 건강 | 방어 수치 |
| 지능 | 마법 공격 |
| 지혜 | **마법 내성과 지원 위력** (치유·버프) |

물리와 마법이 공격과 방어까지 대칭을 이룹니다.

| | 공격 | 방어 |
|---|---|---|
| 물리 | 힘(근접), 민첩(원거리) | 건강 |
| 마법 | 지능 | 지혜 |

마법 계열은 지능과 지혜를 시전에 씁니다. 지혜가 방어 능력치로만 읽히지 않도록 치유·버프 같은 능동 기능을 반드시 붙입니다.

### 3-3. 내성과 저항의 정의

- **내성**: 마법 자체를 회피하는 굴림입니다.
- **저항**: 마법 피해를 줄이는 개념입니다.

BG3의 저항은 "피해 유형을 절반으로 줄이는" 개념이라 위 정의와 다릅니다. 저항을 어느 능력치가 맡는지는 ❓입니다(7장).

### 3-4. 뒤로 미룬 것

- **흘려내기** 스킬의 판정은 능력치 체계를 정한 뒤에 정합니다.
- **치명타** 시스템은 손볼 수 있어서 보류합니다. 현재 `d20 자연 20 = 치명타`를 임시로 유지합니다.

## 4. 능력치 시스템: BG3 기준

### 4-1. 공식 (숙련을 뺀 형태)

BG3 위키로 확인한 항목은 (확인), 5e 규칙에 기대어 적은 항목은 (5e), 플레이어 설명만 있는 항목은 (미확인)으로 표시했습니다.

| 항목 | BG3 / 5e 방식 | 숙련을 뺀 형태 |
|---|---|---|
| 보정값 | `(점수 − 10) ÷ 2` 내림. 점수 10~11이 +0 (확인) | 변화 없음 |
| 무기 명중 | `d20 + 보정값 + 숙련` vs AC. 근접은 힘, 원거리는 민첩, 정교함 무기는 둘 중 높은 쪽 (확인) | `d20 + 보정값` |
| 주문 명중 | `d20 + 시전 능력치 보정값 + 숙련` (확인) | `d20 + 시전 능력치 보정값` |
| 피해 | 무기 주사위 + 능력치 보정값. 치명타는 피해 주사위 2배 (5e) | 변화 없음 |
| 내성 DC | `8 + 숙련 + 시전 능력치 보정값` (확인) | `8 + 시전 능력치 보정값` |
| 내성 굴림 | `d20 + 해당 능력치 보정값 (+ 숙련 내성이면 숙련)` (5e) | `d20 + 해당 능력치 보정값` |
| 이니셔티브 | `d4 + 민첩 보정값`. 동점이면 민첩 점수가 높은 쪽. 민첩 판정이 아님 (확인) | 변화 없음 |
| AC | 방어구 기본값 + 민첩 보정값. 경갑은 전부, 중갑은 +2까지, 중갑(판금 등)은 0. 방패 +2 (확인) | 변화 없음 |
| 최대 HP | 레벨마다 건강 보정값이 더해짐. 음수도 포함 (확인) | 변화 없음 |
| 집중 유지 내성 | 건강 내성, DC `max(10, 받은 피해 ÷ 2)` (미확인) | 변화 없음 |

### 4-2. 능력치가 관여하는 곳 (BG3)

| 능력치 | 관여하는 곳 |
|---|---|
| 힘 | 근접 무기 명중·피해, 운동(밀치기), 점프 거리, 소지 무게, 힘 내성 |
| 민첩 | 이니셔티브, AC, 원거리·정교함 무기 명중·피해, 곡예·손재주·은신, 민첩 내성 |
| 건강 | 레벨당 HP, 집중 유지, 건강 내성 (독·질병 등) |
| 지능 | 마법사 시전 능력치(주문 명중·DC), 학문 계열 기술, 지능 내성 |
| 지혜 | 성직자·드루이드·레인저 시전 능력치, 감지·통찰·의술, 지혜 내성 |

일부 직업 특성은 AC나 DC 계산에 다른 능력치를 끼워 넣습니다(예: 몽크의 맨몸 방어는 지혜). 직업을 늘릴 때 따로 정리합니다.

### 4-3. 이 게임에 필요한 것

| 필요 | 지금은 제외 가능 |
|---|---|
| 명중, 피해, AC, 내성 DC, 내성 굴림, 이니셔티브, 대결(밀치기·만능팔), HP, 시전 능력치 | 소지 무게, 점프 거리, 은신·곡예·손재주, 감지·통찰, 설득 같은 대화 판정, 기본 지각 |

### 4-4. 현재 게임에서 바뀌는 것

구조는 이미 5e와 비슷해서(d20, AC, DC, 내성, 유리/불리, 치명타) 바뀌는 것은 아래입니다.

| 현재 | BG3 기준 | 상태 |
|---|---|---|
| 능력치 4개(정신 하나) | 5개(정신이 지능과 지혜로 갈라짐) | ✅ |
| 힘, 민첩 | 그대로 승계 | ✅ |
| 정신: 충격 화살의 기절 내성 | 마법 내성은 지혜가 승계하는 방향. 물리 유래 상태 이상 회피를 누가 맡는지는 ❓ | ❓ |
| 건강: 표시만 | HP와 방어 수치를 맡음. 범위는 ❓ | ❓ |
| 지능: 없음 | 마법 공격을 맡음 (마법 공격이 구현되면) | 신규 |
| 공격 보너스·DC·AC·피해 보정 상수 | 능력치에서 계산 | ❓ |
| 점수 없이 보정값만 | BG3는 점수 → 보정값 | ❓ |

## 5. 직업과 역할군

### 5-1. 직업별 주요 능력치 (BG3 기준)

| 직업 | 주 | 부 | 비고 |
|---|---|---|---|
| 전사(바바리안 계열 포함) | **힘** | **건강** | 중갑이면 민첩이 AC에 더해지지 않아 낮아도 손해가 거의 없음 |
| 궁수(레인저·궁술 전사) | **민첩** | 지혜, 건강 | 민첩이 명중·AC·이니셔티브를 모두 맡음. 현재 궁수의 정신 +1이 지혜 역할 |
| 마법 계열 | **지능** 또는 **지혜** | 건강, 민첩 | 시전 능력치는 주문 명중과 내성 DC에 쓰이며, BG3에서 주문 피해에는 보정값이 보통 더해지지 않음 |

매력을 뺀 뒤 BG3 직업의 시전 능력치는 아래처럼 옮깁니다.

| 시전 능력치 | 직업 |
|---|---|
| 지능 | 마법사, 소서러·워락·음유시인(매력에서 이동) |
| 지혜 | 성직자, 드루이드, 레인저 |

팔라딘은 힘 중심에 지혜 주문을 일부 쓰는 하이브리드로 둡니다. ❓ 직업을 실제로 추가할 때 정합니다.

관찰한 점입니다.
1. **건강이 거의 모든 역할의 부 능력치**입니다. HP는 누구에게나 이득이라 선택의 폭이 좁아집니다. 건강을 주 능력치로 삼는 역할(탱커)을 두거나, AC를 민첩에서 얻는 회피형과 중갑과 건강으로 버티는 방어형을 대비시키는 장치가 필요합니다.
2. **전사가 힘과 건강을 혼자 씁니다.** 정체성은 분명하지만 힘을 쓰는 다른 역할이 없습니다. 근접을 탱커(건강 주, 힘 부)와 광전사(힘 주, 건강 부)로 나누면 두 능력치 모두 주 능력치인 역할이 생깁니다. ❓
3. **민첩이 가장 쓰임이 많습니다.** 이니셔티브, AC, 원거리 명중을 모두 맡아서 가장 강해지기 쉽습니다. 밸런스를 주의합니다.
4. **지능과 지혜의 구분**은 지능 = 공격·군중 제어, 지혜 = 지원·치유로 나누는 안이 자연스럽습니다. ❓

### 5-3. 초기 구성 제안 ❓

| 직업 | 주 | 부 |
|---|---|---|
| 전사 (탱커/광전사) | 힘 또는 건강 | 건강 또는 힘 |
| 도적 (근접 암살) | 민첩 | 지능 |
| 궁수 | 민첩 | 지혜 |
| 마법사 | 지능 | 건강 |
| 성직자 | 지혜 | 건강 |

모든 능력치가 한 번 이상 주 능력치가 되고, 근접·암살·원거리·마법·지원이 모두 나옵니다.

## 6. 변형 후보: 주사위 능력치와 면 업그레이드 ⏸

BG3 기준을 만든 뒤 얹는 변형 후보입니다. 아래 "변형안 내 결정"은 이 변형을 채택할 때 적용합니다.

### 6-1. 개념

- 능력치를 고정 보정값이 아니라 **면 값 배열을 가진 주사위**로 둡니다. 예: d4는 `[1,2,3,4]`.
- 주사위 **모양은 고정**해서 캐릭터의 성향을 정합니다. 작은 주사위는 안정적이고, 큰 주사위는 평균이 높고 변동이 큽니다.
- 성장은 **면 값을 +1씩 올리는 업그레이드뿐**입니다. 더 큰 다면체로 올리는 업그레이드는 두지 않습니다.
- 처음에는 능력치 7종(힘, 정신, 명중, 방어, 저항, 내성, 민첩) 구상이었으나, BG3 능력치 체계를 기준으로 삼게 되면서 이 구상은 변형 후보로 내려갔습니다.

### 6-2. 성장 규칙 (제안 ❓)

면이 모두 같은 숫자로 수렴하면 재미가 없으므로, 각 면의 상한을 **초기값 + k**로 둡니다. 주사위가 평평해지지 않고, 모양이 영구히 변동성을 정합니다. 업그레이드 1회에 면 `n/4`개 정도를 +1 하면 모양에 상관없이 한 번당 평균 상승이 0.25~0.33으로 비슷해집니다.

k = 3일 때입니다.

| 모양 | 시작 평균 | 완성 평균 | 표준편차 | 한 번에 올리는 면 | 업그레이드 횟수 |
|---|---|---|---|---|---|
| d4 | 2.5 | 5.5 | 1.1 | 1 | 12 |
| d6 | 3.5 | 6.5 | 1.7 | 2 | 9 |
| d8 | 4.5 | 7.5 | 2.3 | 2 | 12 |
| d10 | 5.5 | 8.5 | 2.9 | 3 | 10 |
| d12 | 6.5 | 9.5 | 3.5 | 3 | 12 |

- 절대면 자리는 업그레이드에서 제외하므로(6-3), 위 횟수는 다시 계산해야 합니다.
- 큰 주사위가 처음부터 끝까지 평균 우위를 가집니다. 대기만성은 아닙니다.
- 능력치 보정값을 직접 +1 올리면 명중과 피해에 동시에 영향을 줘서 기대 피해가 약 21%(AC 12 기준 전사) 오르지만, 주사위 면 +1은 d8 기준 평균 +0.125라 1.7% 수준입니다. 두 성장의 크기가 10배 이상 차이 나므로 어느 쪽을 성장 단위로 삼을지 정해야 합니다.

### 6-3. 절대면 (변형안 내 결정 ✅)

**절대면**은 특수한 효과를 가진 면의 총칭입니다. 면 값이 아니라 **면의 자리**에 붙고, 업그레이드에서 제외합니다.

| 용어 | 뜻 |
|---|---|
| 절대성공면 | 그 굴림을 상황에 맞게 최상으로 확정하는 면 |
| 절대실패면 | 그 굴림을 상황에 맞게 최악으로 확정하는 면 |

모양별 개수입니다. 작은 주사위가 절대실패 확률이 더 높은 것은 의도입니다.

| 모양 | 절대성공면 | 절대실패면 |
|---|---|---|
| d4 | 없음 (0%) | 1개 (25%) |
| d6 | 없음 (0%) | 1개 (16.7%) |
| d8 | 1개 (12.5%) | 1개 (12.5%) |
| d10 | 2개 (20%) | 1개 (10%) |
| d12 | 3개 (25%) | 1개 (8.3%) |

효과는 굴림의 종류에 따라 다릅니다.

| 굴림 | 분류 | 절대성공면 | 절대실패면 |
|---|---|---|---|
| 명중 | 판정 | 명중 확정 (치명타는 아님) | 빗나감 확정 |
| 내성 | 판정 | 성공 확정 | 실패 확정 |
| 대결 | 판정 | 승리 | 패배 |
| 피해 보정, 방어 경감, 이니셔티브 등 수치 | 수치 | 한 번 더 굴린 값의 **2배** | **0** |

- 수치에서 재굴림 결과가 다시 절대성공면이면 그 주사위의 **현재 면 값 중 최댓값**으로, 절대실패면이면 **최솟값**으로 칩니다. 연쇄는 없고, 이렇게 치환한 값에 ×2를 적용합니다.
- 내성 굴림의 d20 자연수는 지금처럼 합계로만 판단합니다. 절대면은 스탯 주사위에만 있으므로 이 규칙과 충돌하지 않습니다.
- 명중에도 절대면을 적용합니다. 치명타는 보류합니다.
- 대결에서 **양쪽이 모두 절대면**이면 **플레이어 쪽 결과를 따릅니다**.

| 플레이어 | 적 | 결과 |
|---|---|---|
| 절대성공 | 절대성공 | 플레이어 승 |
| 절대성공 | 절대실패 | 플레이어 승 |
| 절대실패 | 절대성공 | 플레이어 패 |
| 절대실패 | 절대실패 | 플레이어 패 |
| 일반 | 절대성공 | 적 승 |
| 일반 | 절대실패 | 적 패 |

- 쓰지 않는 말: 대성공, 대실패. d20의 치명타·자동 실패와 헷갈리지 않게 합니다.
- ❓ 같은 명중에서 d20이 자연 1인데 스탯 주사위가 절대성공면이면 어느 쪽이 이기는지는 치명타 재설계 때 정합니다. 임시 기본값은 절대면 우선입니다.

### 6-4. 굴림 시점 (제안 ❓)

- 굴림에 더하는 쪽(명중, 내성, 대결)은 굴립니다.
- 기준값(AC, DC)은 고정입니다. 주사위에서 기준값을 뽑는 규칙은 후보가 최소 면, 평균 내림, 중앙값이며 아직 정하지 못했습니다. 최소 면은 큰 주사위에 불리합니다.
- 방어를 BG3처럼 장비와 AC로 두면 이 규칙이 필요 없을 수도 있습니다.

### 6-5. 방어·저항 굴림

- 방어는 맞을 때마다 **방어 주사위를 굴려 피해를 깎는** 방식입니다 ✅.
- 방어 굴림의 **하한은 1**입니다. `피해 = max(1, 피해 − 방어 굴림)` ✅.
- 방어와 저항을 기본 능력치로 둘지, 장비의 경감 주사위로 둘지는 ❓입니다. 장비로 두면 능력치가 5개로 줄고, 방어 굴림 연출은 유지됩니다. 경감을 장비의 고정값으로 두면 굴림이 4개로 줄지만 방어 굴림 결정을 번복합니다. 방어 굴림의 평균이 공격 피해의 상당 부분이 되면 대부분 1로 뭉개지므로 두 규모를 맞춰야 합니다.

### 6-6. 피해 주사위와 스킬 (제안 ❓)

- 힘·지능 주사위는 지금 피해 **보정값 자리**를 대체합니다. 피해 주사위(무기, 스킬)는 따로 둡니다.
- 스킬의 차별성은 주사위를 쓰는 방식으로 만듭니다. 예: 능력치 주사위를 두 번 굴려 높은 쪽, 스킬 고유 주사위 + 능력치 굴림, 합산, 가장 높은 면 고정, 낮은 면 재굴림.
- 피해 주사위가 능력치 주사위 하나로 통일되면 스킬 피해가 비슷해지는 문제가 있어서 이 방식을 제안합니다.

### 6-7. 기존 결정과의 충돌 ❓

- [기획 현황](DESIGN_STATUS.md)에 2026-10-07 결정이 있습니다: **육성은 아이템뿐이고, 레벨업과 재화는 없다.** 면 업그레이드 성장은 이 결정과 부딪칩니다.
- 이 변형을 채택하려면 육성 결정을 바꾸거나, 면 업그레이드를 **아이템으로만 얻게** 해야 합니다. 예를 들어 장비가 특정 면의 값을 올리는 "면 부착"이 있습니다. 후자는 기존 결정과 맞습니다.
- 어느 쪽이든 결정은 Issue에서 확인한 뒤에 정합니다.

## 7. 정해야 할 것 ❓

1. **점수와 보정값**: BG3의 능력치 점수를 도입할지, 지금처럼 보정값만 쓸지. 점수를 도입하면 용어집의 보정값과 "능력치 점수는 쓰지 않음" 규칙을 바꿔야 합니다.
2. **이니셔티브**: BG3의 `d4 + 민첩 보정값`을 따를지, 지금의 `d20`을 유지할지.
3. **AC**: 방어구와 민첩에서 계산할지, 지금처럼 직업 상수 + 장비로 둘지. 숙련 제거에 따른 일괄 −2도 같이 정합니다.
4. **건강의 방어 수치 범위**: HP만인지, 피해 경감도 포함하는지. 마법 피해 경감(저항)을 누가 맡는지.
5. **상태 이상 회피와 벗어나기**: 충격 화살의 기절 같은 물리 유래 상태 이상을 지혜가 맡는지, 건강이 맡는지. 걸린 뒤 벗어나는 판정이 필요한지.
6. **지능과 지혜의 주문 구분**: 지능 = 공격·군중 제어, 지혜 = 지원·치유로 나눌지. 마법 피해에 시전 능력치 보정값을 더할지(BG3는 보통 더하지 않음).
7. **내성 DC의 시전 능력치**: `8 + 시전 능력치 보정값`에서 지능과 지혜 중 무엇인지, 직업·스킬마다 다른지.
8. **전사 분리와 초기 직업 구성**: 5-3절 구성을 쓸지, 전사를 탱커와 광전사로 나눌지.
9. **육성 결정과의 충돌**: 6-7절. 변형을 채택할 때만 필요합니다.
10. **변형안의 미결**: 성장 규칙 k와 업그레이드 방식(6-2), 기준값 규칙(6-4), 방어·저항 구성(6-5), 같은 명중에서 d20 자연수와 절대면의 충돌(6-3).
