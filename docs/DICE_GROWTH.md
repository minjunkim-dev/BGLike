# 주사위 육성 논의

> 능력치 주사위를 어떻게 키울지, 절대면과 그 이점을 어떻게 둘지 논의한 내용을 모은 문서입니다. 능력치와 판정의 확정 규칙은 [능력치와 주사위 판정 기획서](ABILITY_SYSTEM.md)에 있습니다.
>
> - 기준일: 2026-10-28 개정 (최초 2026-10-23)
> - **상태: ⏸ 보류. 성장과 절대성공의 추가 이점은 구현하지 않습니다.** 능력치 성장(주사위 레벨), 절대성공면 획득, 치명타 재도입은 이 문서가 확정되고 Issue로 넘어온 뒤에 개발을 시작합니다. 절대면의 **시작 상태와 판정 효과**(5장)는 능력치 기획서 4-11이 정하며 구현 범위입니다.
> - **개정 안내**: 능력치 구성이 바뀌었고(자연 → 건강, 4장 이하의 능력치 이름은 개정 전 표기), 판정이 명중굴림·내성굴림으로 바뀌었습니다. 성장의 **단위는 주사위 레벨**(4장), **얻는 방식은 막 최초 클리어마다 레벨업**(3장)으로 정했습니다. 재화는 쓰지 않습니다.

> - 표시: ✅ 정해짐(변형 채택 시 적용) · 🟡 제안 · ❓ 정해야 함 · ⏸ 보류

## 2. 육성 결정과의 충돌

- [기획 현황](DESIGN_STATUS.md)에 2026-10-07 결정이 있습니다: **육성은 아이템뿐이고, 레벨업·능력치 성장·재화는 없다.** [게임 구조 기획서 1장](GAME_STRUCTURE.md#1-게임-목표)도 같습니다.
- 2026-10-28에 기획자가 **막 최초 클리어마다 레벨업**하기로 정했습니다 ✅ (3장). 이 결정이 2026-10-07의 "레벨업·능력치 성장 없음"을 **바꿉니다**. 재화는 여전히 없습니다.
- 아이템 중심 육성은 그대로입니다. 레벨업은 장비와 별개로 더해집니다.
- 저장소 규칙상 Issue에서 결정을 남긴 뒤 문서를 고칩니다 (#322).

## 3. 성장 방식 후보

성장의 **단위는 주사위 레벨**(4장)입니다 ✅. 얻는 방식은 다음으로 정했습니다 ✅ (2026-10-28).

| 항목 | 결정 |
|---|---|
| 얻는 때 | **막을 처음 클리어할 때** 레벨업 1회. 막 재시작이나 이미 깬 막을 다시 깨도 오르지 않음 |
| 한 번의 효과 | **6개 능력치 전부 주사위 레벨 +1** (선택 없음) |
| 적용 대상 | **보유한 모든 캐릭터가 같은 레벨**을 공유. 나중에 얻는 캐릭터도 같은 레벨 |
| 재화 | 쓰지 않음 |
| 총량 | 막 3개 → 레벨 최대 3 (아래 🟡) |

> ✅ **졸업 레벨**: 3막을 깨면 졸업 화면으로 끝나고 저장이 삭제되므로([게임 구조 기획서](GAME_STRUCTURE.md)), 3막 클리어로 받는 레벨 3은 플레이에서 쓰이지 않습니다. **플레이 중 실제 최대는 2**(1막 클리어 후 1, 2막 클리어 후 2)입니다. 이대로 둡니다 (2026-10-28). 지금 개발 단계가 3막까지의 플레이 경험을 시험하는 단계이기 때문입니다.

아래 표는 검토한 후보입니다. 채택한 것은 "막 보상" 계열이며, 포인트 분배 대신 **전체 능력치 자동 +1**로 정했습니다.

| 안 | 내용 | 이 게임과의 궁합 | 비용 |
|---|---|---|---|
| 막 보상 포인트 ✅ | 막을 클리어할 때마다 능력치 포인트를 분배 → **전체 능력치 자동 +1로 채택** | 3막 구조와 일치. 레벨·경험치 없이 구현 | 낮음 |
| 스테이지 보상 선택 | 스테이지 승리 시 업그레이드 3개 중 1개 선택 (9번) | 로그라이크 감각. 빌드 선택이 자주 생김 | 중간 |
| 레벨·경험치 | 레벨업마다 능력치 상승 | 가장 전통적이지만 육성 결정을 크게 바꿈 | 높음 |
| 사용 기반 | 쓴 능력치가 오름 | 스킬이 능력치를 지정하는 구조와 맞음. 반복 사용 악용 위험 | 중간 |
| 주사위 레벨 | 포인트나 아이템으로 레벨 +1 (4장) | 단위는 정해짐. 획득 방법은 재화 논의에서 정함. 아이템으로 맞출 수 있음 | 낮음 |
| 아이템 병행 | 위 방식 + 장비 보정 | 현재 장비 중심 구조를 살림 | 낮음 |

## 4. 주사위 레벨

### 4-1. 개념 ✅

성장은 **주사위 레벨**로 합니다. 기본 주사위(모양, 면 구성, 절대면)는 바꾸지 않습니다. 레벨업은 6개 능력치에 한꺼번에 적용되므로(3장) **능력치 6종과 모든 캐릭터가 같은 레벨 하나를 공유**합니다.

```text
굴림 값 = 주사위 눈 + 주사위 레벨
```

- 레벨은 **0에서 시작**합니다. 레벨 0이면 능력치 기획서의 규칙 그대로입니다.
- 막을 처음 클리어하면 레벨이 1 오릅니다 (3장). 화면에는 `힘 d20 +3`처럼 기본 주사위 옆에 레벨을 붙입니다.
- 모양은 바뀌지 않습니다. 큰 주사위와 작은 주사위의 적성 차이는 영구히 유지됩니다.
- 모양과 무관하게 **한 번 성장은 레벨 +1**입니다. 모양별로 필요한 성장 횟수를 달리하는 보정은 하지 않습니다.
- **상한은 막 수에 따라 3**이고 플레이 중 최대는 2입니다 (3장 🟡). 막이 늘면 상한도 따라 늘어납니다.
- 레벨은 캐릭터가 아니라 **파티(세이브)의 값**입니다. 능력치별 레벨 구조는 필요 없습니다. 나중에 능력치 일부만 올리는 특수 성장이 생기면 그때 추가합니다.

### 4-2. 레벨이 적용되는 곳 ✅

| 곳 | 적용 |
|---|---|
| 명중굴림, 내성굴림 | 굴림 값에 레벨을 더함 (공격 가산·방어 가산과 별개로 더해짐) |
| 피해 굴림 | 능력치 주사위 값에 레벨을 더함 |
| 이니셔티브 | 민첩 주사위 값에 레벨을 더함 |
| 표준값 (AC·DC) | 기본 표준값 + 레벨. 예: 민첩 d8 레벨 2 → AC 5 + 2 = 7 |
| 최대 HP | 레벨 × m ([능력치 기획서 4-9](ABILITY_SYSTEM.md#4-9-피해와-회복-)). m은 수치 설계에서 정함 |
| 이동력 | 적용하지 않음 (이동력은 능력치와 연동하지 않음) |

### 4-3. 절대면과 레벨 ✅

- 절대면의 **판정 효과**(무조건 성공·실패)는 레벨과 무관합니다.
- 숫자로 셀 때 **모든 면에 레벨을 똑같이 더합니다.** 절대실패는 1 + 레벨, 절대성공은 최댓값 + 레벨입니다 ✅ (2026-10-28).
- 굴림 값 = 눈 + 레벨 한 줄이 모든 면에 적용되어 예외가 없습니다. 대신 레벨이 오르면 절대실패의 피해·이니셔티브 숫자도 같이 오릅니다. 명중·내성에서는 절대실패가 레벨과 상관없이 실패입니다.

### 4-4. 장비 가산과의 차이 ✅

주사위 레벨은 주사위 자체에 붙어 그 주사위를 쓰는 모든 곳에 적용됩니다. 장비 가산은 용도별로 따로 붙습니다.

| | 장비 가산 | 주사위 레벨 |
|---|---|---|
| 공격 가산 | 명중굴림, DC에만 | |
| 방어 가산 | AC, 내성굴림에만 | |
| 기타 가산치(피해 보정) | 피해 굴림에만 | |
| 주사위 레벨 | | 그 주사위의 모든 굴림(명중, 내성, 피해, 이니셔티브)과 표준값 |

### 4-5. 성장의 크기 (참고)

- 레벨 +1의 효과는 장비 가산 +1과 같은 성질입니다. 기준값(AC·DC)이 주사위 범위 안에 있을 때 면 하나의 확률(`100 ÷ n`%p)만큼 오르고, 범위 밖이면 오르지 않습니다.
- 같은 레벨 3에서도 기준값에 따라 모양별 효과가 다릅니다 (시작 상태, 장비 없음).

| 기준값 | d4 | d20 |
|---|---|---|
| AC 5 | 25% → 75% (+50%p) | 80% → 95% (+15%p) |
| AC 8 | 25% → 25% (±0%p) | 65% → 80% (+15%p) |
| AC 12 | 25% → 25% (±0%p) | 45% → 60% (+15%p) |

- 작은 주사위는 범위 안의 좁은 기준값에서만 크게 오르고, 큰 주사위는 넓은 기준값에서 꾸준히 오릅니다. 큰 주사위는 성공률 천장(95%)에 먼저 닿습니다. **모양 배분이 곧 밸런스**라는 원칙과 같습니다.
- 레벨 +1은 모든 면을 +1 올리므로 평균, 피해, 표준값(AC·DC)이 정확히 +1 오릅니다. 큰 주사위와 작은 주사위의 평균 차이는 성장해도 그대로입니다.

### 4-6. 기본 성장에 두지 않는 것 ✅

면 단위 업그레이드(면 하나 +1, 랜덤 면, 후보 중 고르기, 구간 단위, 낮은 면부터 자동, 높은 면 복사)는 기본 성장 시스템에 두지 않습니다. 필요하면 특수한 상황이나 스킬로 따로 만듭니다.

| 검토한 방법 | 기본 성장에서 뺀 이유 |
|---|---|
| 면 단위 배분 | 면 개수가 일반면 수로 나누어떨어지지 않아 비대칭이 생기고 규칙이 복잡함 |
| 랜덤 면 업그레이드 | 평균은 같고 모양만 운에 맡겨짐. 계획 여지가 없음 |
| 랜덤 후보 중 고르기 | 후보 UI가 필요하고 큰 주사위에는 어색함 |
| 낮은 면부터 자동 | 결국 모든 면이 같은 값으로 수렴함 |
| 모양별 성장 횟수 보정 | 효과가 기준값 범위에 따라 달라 하나의 보정표로 맞출 수 없음 |

## 5. 절대면

✅ 판정 규칙과 시작 상태는 [능력치 기획서 4-11](ABILITY_SYSTEM.md#4-11-절대면-)이 정합니다. 이 장은 성장과 관련된 부분을 정리합니다.

**절대면**은 효과가 있는 면의 총칭입니다. 면 값이 아니라 면의 **자리**에 붙고, 판정 효과는 주사위 레벨의 영향을 받지 않습니다 (숫자로 셀 때는 4-3처럼 레벨을 더함).

| 용어 | 뜻 |
|---|---|
| 절대성공면 | 명중굴림·내성굴림에서 값과 무관하게 성공을 확정하는 면. 숫자로 셀 때 레벨 0에서는 최댓값, 성장 후에는 최댓값 + 레벨 |
| 절대실패면 | 값과 무관하게 실패를 확정하는 면. 숫자로 셀 때 레벨 0에서는 1, 성장 후에는 1 + 레벨 |

쓰지 않는 말: 대성공, 대실패 (d20 치명타·자동 실패와 헷갈리지 않게).

### 5-1. 모양별 개수 ✅

모든 주사위에 절대실패면이 하나 있습니다. 작은 주사위가 절대실패 확률이 높은 것은 의도입니다.

| 모양 | 절대실패면 | 절대성공면 (시작 → 최대) |
|---|---|---|
| d4 | 1개 (25%) | 1개 (25%) 🟡 |
| d6 | 1개 (16.7%) | 1개 (16.7%) 🟡 |
| d8 | 1개 (12.5%) | 1개 (12.5%) 🟡 |
| d10 | 1개 (10%) | 1개 (10%) 🟡 |
| d12 | 1개 (8.3%) | 1개 (8.3%) → 최대 1개 |
| d20 | 1개 (5%) | 1개 (5%) → 최대 3개 (15%) |

- 🟡 **시험용 임시** (2026-10-28): 3막까지의 플레이 경험을 시험하기 위해 **모든 주사위가 절대성공면 1개로 시작**합니다. 원래 기획은 d4~d10은 없음, d12는 0개 → 1개, d20만 1개 → 3개였고, 작은 주사위일수록 불리한 것은 의도한 설계였습니다. 시험 뒤 이 원래 기획으로 되돌릴지, 유지할지 다시 정합니다.
- 모든 주사위가 절대성공면 1개를 가지면 표준값 이상 성공률은 그대로 50%입니다 (능력치 기획서 4-3). 바뀌는 것은 높은 기준값에서 성공률 바닥이 0이 아니라 `100 ÷ n`%가 된다는 점입니다.
- 시작 이후에 **추가로** 얻는 절대성공면은 성장으로 얻을 수 있게 할지 정해야 합니다 (5-3).

### 5-2. 일반면 배치 ✅

아래 수치는 레벨 0 기준입니다. 절대성공을 얻으면 **가장 높은 일반면부터** 절대성공으로 바뀝니다. 레벨 0에서 절대성공은 숫자로 셀 때 최댓값이라 평균이 거의 변하지 않고, 평소 승률은 그대로입니다. 올라가는 것은 기준값을 넘지 못하는 상대에게 이길 확률입니다.

| d20 | 절대성공 1개 (시작) | 2개 | 3개 |
|---|---|---|---|
| 일반면 | 2~19 | 2~18 | 2~17 |
| 평균 | 10.50 | 10.55 | 10.65 |
| 표준값 | 11 | 11 | 11 |
| 성공률 범위 | 5~95% | 10~95% | 15~95% |

시작 상태에서 모든 주사위가 같은 배치입니다. 예: d12는 12가 절대성공이고 일반면은 2~11, 평균 6.50. d8은 8이 절대성공, 일반면 2~7.

### 5-3. 얻는 방법 ❓

시작 상태(모든 주사위 1개)는 정했습니다. 그 **이후에 추가로** 얻는 방법은 3장의 성장 방식과 별개로 정합니다. 그 전에는 구현하지 않습니다.

## 6. 절대성공의 이점과 치명타

치명타는 범용 d20 판정의 자연 20에 묶여 있어서 그 판정과 함께 사라졌고, 구현은 비활성입니다. d20은 능력치 주사위로 남아 있고, 그 절대성공면은 계속 유효해서 판정 성공을 확정하지만 자연 20 같은 치명타 효과나 추가 피해는 주지 않습니다.

절대성공이 나왔을 때 판정 성공 외에 추가 이점을 줄지는 **나중에 다룹니다** ❓. **치명타 제도는 그 이점의 후보 중 하나**입니다. 정해지기 전까지 절대성공은 성공을 확정하는 효과만 가집니다.

| 후보 | 내용 | 비고 |
|---|---|---|
| 치명타 제도 | 절대성공이 나오면 치명타로 처리. 효과(피해 주사위 추가 등)는 정해야 함 | 치명타는 명중굴림에만 해당. 내성굴림은 별도 검토 |
| 다른 이점 | 피해 증가 등 치명타 외의 추가 이점 | 후보가 생기면 추가 |
| 차이 기준 | 공격 굴림이 AC를 N 이상 넘으면 치명타. N은 주사위 크기에 비례해 정함 | 압도적 승리가 치명타. 큰 주사위가 쉽게 냄 |
| 이점 없음 | 도입하지 않음 | 가장 단순함. 극단 결과는 절대면의 성공·실패 확정만 담당 (현재) |

## 7. 정리된 이전 논의

- **방어·저항 굴림(피해 경감)**: 맞을 때 방어 주사위로 피해를 깎고 하한을 1로 두는 안이 있었습니다. 방어자가 굴리지 않고 AC가 명중을 막는 구조로 바뀌면서 폐기합니다.
- **능력치 점수와 보정값**: 능력치가 주사위가 되면서 필요 없어졌습니다.
- **기준값(AC, DC)을 주사위에서 뽑는 규칙**: 개정으로 AC와 DC를 주사위의 표준값(평균 반올림)에서 만들기로 했습니다 ([능력치 기획서 4-3](ABILITY_SYSTEM.md#4-3-방어-능력치와-acdc-)).

## 8. 정해야 할 것

**정해진 것**: 절대면과 레벨의 숫자 처리(모든 면에 레벨을 똑같이 더함), 시작 상태는 모든 주사위에 절대성공면 1개(시험용 임시), 3막 클리어 레벨(졸업 레벨)은 쓰임 없이 그대로 둠, 성장 단위(주사위 레벨, 0에서 시작, 모양과 무관하게 한 번 +1), 얻는 방식(막 최초 클리어마다 6개 능력치 전부 +1, 모든 캐릭터 공유, 재화 없음), 면 단위 업그레이드는 기본 성장에 두지 않음, 장비 가산과 별개.

| # | 항목 |
|---|---|
| 1 | 레벨업으로 파티가 강해지는데 몬스터는 막별로 강화하지 않는 구조의 밸런스 점검 ([게임 구조 기획서 2장](GAME_STRUCTURE.md#2-진행-구조)). 같은 몬스터에 대한 명중률·피격률이 레벨마다 달라짐 |
| 2 | 절대성공면을 추가로 얻는 방법 (5-3). 시작은 모든 주사위 1개(시험용 임시) |
| 3 | 절대성공의 추가 이점, 치명타 (6장) |
| 4 | 시험 뒤 모든 주사위 절대성공 1개를 유지할지 원래 기획으로 되돌릴지 (5-1) |
| 5 | 성장 규칙에 맞춘 모양 배분 원칙 |
