## 3. 만들 것

자세한 규칙은 기획서의 해당 절을 봅니다. **필수**는 빠지면 프로토타입 목적을 이룰 수 없는 항목입니다.

| 항목 | 기획서 | 우선순위 |
|---|---|---|
| 정신 능력치, 기본 공격 타입(기회 공격 가능/불가), 궁수 사거리 6 | 2장 | 필수 |
| 턴 자원: 행동 / 보조 행동 / 반응 | 3-3 | 필수 |
| 턴 종료: 자동 종료 없음, 할 일이 없으면 버튼 강조 | 3-4 | 필수 |
| 유리 / 불리 (기절 대상 공격, 원거리 공격 시 옆에 적) | 4-2 | 필수 |
| 내성 굴림 | 4-3 | 필수 |
| 기회 공격 + 반응 확인 창 | 5-2, 9-5 | 필수 |
| 스킬 6개 (전사 3, 궁수 3) + 스킬 패널 | 5-3, 9-3, 9-4 | 필수 |
| 전투 화면 배치: 턴 순서 바, 현재 유닛 패널, 로그, 스킬 패널, 턴 종료 버튼, 유닛 위 표시 | 9-1 ~ 9-3 | 필수 |
| 기절 | 6장 | 필수 |
| 적 AI 갱신 | 7장 | 필수 |
| 턴 묶음 + 턴 순서 바 초상으로 유닛 전환 | 3-2, 9-4 | 일정이 밀리면 세 번째로 뺌 |
| 물약 | 5-4 | 일정이 밀리면 두 번째로 뺌 |

## 5. 기획 검수 기준

10월 11일에 기획 담당이 아래 상황을 직접 만들어 확인합니다. 개발 중 자체 확인에도 쓸 수 있습니다.

### 턴과 자원

- [ ] 한 턴에 이동을 나눠 쓰면서 행동 1회, 보조 행동 1회를 각각 쓸 수 있다.
- [ ] 할 수 있는 동작이 없으면 턴 종료 버튼의 색이 바뀌고, 누르기 전에는 턴이 끝나지 않는다.
- [ ] 스킬 컨테이너 제목의 ● ▲ ◆가 자원을 쓰면 ○ △ ◇로 바뀐다.
- [ ] 이니셔티브에서 아군이 연달아 있으면 턴 순서 바의 초상을 눌러 두 유닛을 원하는 순서로 번갈아 조작할 수 있다. (턴 묶음)

### 반응

- [ ] 아군 전사 옆의 적이 걸어서 벗어나면 기회 공격 확인 창이 뜬다.
- [ ] 아군 궁수 옆의 적이 벗어날 때는 확인 창이 뜨지 않는다. (기회 공격 불가 타입)
- [ ] 전사가 공격에 맞으면 흘려내기 확인 창이 뜨고, 성공하면 피해가 없다.
- [ ] 한 라운드에 기회 공격을 쓰면 흘려내기를 쓸 수 없다. (반응 공유)
- [ ] 적이 물러서며 쏘기를 쓰고 벗어나면 기회 공격이 일어나지 않는다.

### 판정

- [ ] 궁수가 적이 옆에 있는 상태에서 쏘면 불리가 적용되고, 로그에 주사위 두 개가 보인다.
- [ ] 기절한 대상을 공격하면 유리가 적용된다.
- [ ] 명중률 미리보기에 유리/불리가 반영된다.
- [ ] 적을 한 번 누르면 현재 유닛 패널 자리에 그 적의 HP, AC, 상태가 나온다.

### 스킬과 상태 이상

- [ ] 스킬 패널에는 지금 조작 중인 유닛의 스킬만, 행동 / 보조 행동 / 반응 컨테이너로 나뉘어 나온다. 궁수는 반응 컨테이너가 없다.
- [ ] 각 스킬 버튼 오른쪽에 비용이 자원 기호 개수로 그려지고, 남은 횟수는 버튼 모서리 배지로 나온다. (기획서 9-2 그림 참고)
- [ ] 적 턴에는 현재 유닛 패널에 행동 중인 적의 정보가 나오고, 스킬 패널은 회색으로 남는다.
- [ ] 스킬 6개가 모두 기획서대로 동작하고, 남은 횟수가 보이며, 다 쓰거나 소비할 자원이 없으면 회색으로 비활성화된다.
- [ ] 충격 화살이 명중하고 정신 내성에 실패하면 대상이 다음 턴을 통째로 넘긴다.
- [ ] 표식을 건 대상을 맞히면 추가 피해가 로그에 보인다.
- [ ] 공격한 뒤 몰아치기(보조 행동)를 쓰면 행동 ○이 ●로 다시 채워져, 같은 턴에 한 번 더 공격할 수 있다.
- [ ] 행동을 아직 쓰지 않았으면 몰아치기가 회색이다.

### 공용 동작 (뺀 경우 제외)

- [ ] 밀치기 대결에 이기면 적이 1칸 밀리고, 밀릴 칸이 막혀 있으면 선택할 수 없다.
- [ ] 물약을 쓰면 HP가 회복되고, 유닛당 한 번만 쓸 수 있다.

### 적 AI

- [ ] 적 궁수가 옆에 적이 붙으면 거리를 벌린다.
- [ ] 적 전사가 HP 절반 이하에서 숨 고르기를 쓰고, 그 턴에는 몰아치기를 쓰지 않는다.
- [ ] 적이 반응(기회 공격, 흘려내기)을 자동으로 쓴다.

### 전체

- [ ] 전투를 처음부터 결과 화면까지 막힘 없이 끝낼 수 있다.
