- 내성 DC 11은 풋내기 야만인과 같은 방식으로 정의(`8 + 숙련 2 + 민첩 3` = 13)에서 뺀 예외 값입니다.
- 표식과 충격 화살은 없앴습니다. AI는 인접한 상대가 있으면 물러서며 쏘기로 거리를 벌리고, 사거리 안의 대상을 기본 공격합니다.
- 충격 화살이 없어지므로 적 쪽에는 기절을 거는 수단이 없습니다. 아군의 정신 내성은 지금 몬스터 상대로 쓰이지 않습니다.
- 바뀐 수치의 효과:

| 수치 | 전 | 후 |

| 충격 화살 기절을 버틸 확률 (`d20 + 정신 ≥ 13`) | 45% | 40% |
| 아군 전사의 흘려내기 성공 확률 (`d20 + 1 ≥ DC`) | 45% | 55% |
