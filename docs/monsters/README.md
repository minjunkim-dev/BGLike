## 1. 이 문서를 쓰는 법

- 새 몬스터를 기획할 때 일반 몬스터는 5장, 보스는 7-2의 시트를 복사해 몬스터별 문서(6장)를 만듭니다.
- 시트의 수치와 규칙이 정해지면 전투 시스템 기획서나 게임 구조 기획서로 옮깁니다. 능력치와 판정은 [능력치 기획서](../ABILITY_SYSTEM.md)를 함께 확인합니다. 이 문서에는 컨셉, 장단점, 플레이어의 고민처럼 **왜 그렇게 만들었는지**를 남깁니다.
- 세계관과 이야기는 M7에서 정합니다. 그 전까지 이름은 역할을 드러내는 가칭을 씁니다.
- 외부 이미지 제작은 [공통 유닛 이미지 납품 규격](../UNIT_IMAGE_TEMPLATE.md)을 따릅니다. 현재 실제 도트 외형과 애니메이션은 [#193/#194 제작 기준](../PIXEL_ART.md)을 따릅니다. 이 아트 선택은 몬스터의 전투 수치나 새 스킬을 확정하지 않습니다.

## 2. 디자인 원칙

| 원칙 | 상태 | 내용 |
|---|---|---|
| 컨셉 필수 | ✅ | 모든 몬스터는 컨셉을 가집니다. 컨셉이 스킬과 수치를 정하는 기준입니다 |
| 추상 컨셉 없음 | ✅ | 몬스터는 캐릭터와 달리 소설 같은 추상 컨셉을 쓰지 않습니다. 컨셉은 "무엇을 하는 몬스터인가"를 적은 한 줄입니다 (2026-10-13) |
| 장단점 필수 | ✅ | 모든 몬스터는 장점과 단점을 함께 가집니다. 단점이 없는 몬스터는 만들지 않습니다 |
| 고민 하나 | ✅ | 몬스터 하나는 플레이어의 고민을 하나 만듭니다. 예: "누구부터 잡을까?", "어디에 설까?" 고민이 없으면 체력만 다른 같은 적이 됩니다 |
| 기존 동작 먼저 | ✅ | 새 규칙보다 기존 동작(기절, 밀치기, 기회 공격, 유리/불리, 방어 굴림)의 조합을 먼저 시도합니다. 금지가 아니며, 새 규칙이 필요하면 무엇인지 적고 Issue에 남깁니다 |
| 공략법 | ✅ | 몬스터의 장점마다 그것을 받아칠 아군 수단이 하나 이상 있어야 합니다 |
| 막별 수준 고정 | ✅ | 같은 몬스터는 모든 막에서 같은 수치입니다. 막별 난이도는 배치 수와 종류로 조절합니다. 플레이어가 "같은 몬스터인데 이제 쉽게 잡네"라고 느껴 캐릭터가 강해졌음을 체감하게 하려는 것입니다 (2026-10-14) |

## 3. 등급 ✅

몬스터를 강한 정도로 나눕니다. 지금은 두 등급만 둡니다.

| 등급 | 뜻 | 추가 항목 |
|---|---|---|
| 일반 | 스테이지에 여럿 나오는 기본 몬스터 | 없음 |
| 보스 | 강한 몬스터. 일반 몬스터보다 확실히 강함 | 7장의 높은 체력, 패배 조건, 패턴, 기믹 |

- 등급은 디자인 분류입니다. 보스의 기절 면역(7-1)은 #110~#112에서 구현했습니다.
- 고철로봇 시리즈가 처음 나오는 보스입니다. 나머지 몬스터는 일반입니다.
- 그 사이 등급(예: 정예)은 필요해지면 다시 논의합니다 ❓.
- 아이템 등급과는 별개입니다. 아이템 등급은 [게임 구조 기획서 4-7](../GAME_STRUCTURE.md#4-7-보류한-것-)에서 보류 중입니다.

## 4. 역할 ✅

몬스터는 위치에 따른 역할을 적습니다. 캐릭터의 역할(탱커, 딜러, 서포터)과는 다른 분류입니다.

- **기획용 분류입니다** (2026-10-15). 새 몬스터가 어디서 싸우는지 정리하고, 스테이지 배치에서 역할을 섞는 데 씁니다.
- 코드에 분류값으로 넣을지는 구현에서 판단합니다. 실제 사용처가 생기기 전에는 넣지 않습니다.

| 역할 | 예 |
|---|---|
| 근접 | 풋내기 야만인, 새끼 거미, 고철로봇 |
| 원거리 | 풋내기 궁수 |
| 지원 | 엄마 거미 (새끼를 만듦) |

- 적은 장비를 끼지 않습니다. 물약은 없고(0개), 밀치기는 AI가 쓰지 않습니다.
- 스킬 횟수는 막당이지만, 적은 스테이지마다 새로 나오므로 스테이지마다 다시 채워집니다.

## 7. 보스 몬스터

### 7-1. 보스의 조건 ✅

보스는 일반 몬스터 시트(5장)를 모두 채우고, 아래 네 항목을 더합니다. 보스도 장점과 단점을 함께 가집니다.

| 항목 | 뜻 | 예 |
|---|---|---|
| 높은 체력 | 일반 몬스터보다 크게 높은 HP. 한두 턴에 전투 불능이 되지 않아 패턴을 보여 줄 시간을 만듦 | 일반 몬스터 HP의 몇 배 ❓ |
| 패배 조건 | 보스를 전투 불능으로 만드는 방법이나 플레이어가 지는 조건 | HP 0 / 특정 오브젝트 파괴 / N턴 버티기 ❓ |
| 패턴 | 보스가 반복하는 행동 순서. 플레이어가 읽고 대비할 수 있어야 함 | 2턴마다 범위 공격, 다음 턴 행동 예고 |
| 기믹 | 그 보스에게만 있는 특수 규칙 | HP 50%에 단계 전환, 졸개 소환 |

- 보스는 **기절에 면역**입니다 ✅ (2026-10-14).
- 보스의 드랍은 일반 몬스터와 같습니다 ✅ (2026-10-14).

### 7-2. 보스 시트

5장 시트에 아래를 더합니다.

| 항목 | 내용 |
|---|---|
| 등급 | 보스 |
| 장점 / 단점 | 단점은 공략의 실마리가 됨 |
| 높은 체력 | HP와 그 근거 |
| 패배 조건 | 보스 쪽, 아군 쪽 |
| 패턴 | 턴별 또는 조건별 행동표 |
| 기믹 | 특수 규칙과 화면에 알리는 방법 |
| 단계 | 단계가 있으면 전환 조건과 단계별 변화 |
| 등장 위치 | 막과 스테이지 |
| 보상 | 드랍은 일반 몬스터와 같음 ✅ |

### 7-3. 후속 보스에서 검토할 점 ❓

M5의 세 보스는 HP0 전투 불능·몬스터 전멸 승리 조건과 확정 AI를 사용합니다. 아래는 다른 패배 조건이나 새 보스를 기획할 때 검토할 항목입니다.

| 기존 규칙 | 부딪히는 점 |
|---|---|
| 스테이지 승리 = 몬스터 전멸 ([게임 구조 기획서 2장](../GAME_STRUCTURE.md#2-진행-구조)) | "오브젝트 파괴"나 "N턴 버티기" 같은 패배 조건을 쓰면 승리 조건에 예외가 생김 |
| 적 AI는 공통 규칙 + 유닛별 규칙 | 패턴과 단계는 지금 AI 구조보다 복잡함 |
| 스킬 횟수는 막당 | 보스전 앞에서 스킬을 아끼게 되는지 |

## 8. 새 몬스터 체크리스트

- [ ] 한 줄 컨셉이 있다.
- [ ] 장점과 단점이 모두 있고, 단점이 화면에서 보인다.
- [ ] 등급과 역할이 정해졌다.
- [ ] 플레이어의 고민과 공략법이 있다.
- [ ] 보스라면 높은 체력, 패배 조건, 패턴, 기믹을 모두 채웠다.
- [ ] 새 규칙이 필요하면 무엇인지 적고 Issue에 질문을 남겼다.
- [ ] 이름과 텍스트에 BG3 고유 명칭을 쓰지 않았다.
