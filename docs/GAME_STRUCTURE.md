## 1. 게임 목표

**캐릭터를 육성하면서 3막의 모든 스테이지를 깨는 것(3막 졸업)이 목표입니다.** ✅

- 육성 수단은 **아이템뿐**입니다. 레벨업, 능력치 성장, 재화는 두지 않습니다.
- 이야기와 세계관은 이 구조 위에 나중에 얹습니다 ([로드맵 M7](ROADMAP.md#10-m7-첫-플레이-가능-구간-기획)).

## 2. 진행 구조

### 2-1. 막과 스테이지 ✅

| 항목 | 결정 |
|---|---|
| 구성 | 3막 × 막당 3스테이지 = **전투 9번** |
| 순서 | 1-1 → 1-2 → 1-3 → 2-1 → … → 3-3. 스테이지를 고르지 않음 |
| 스테이지 하나 | 몬스터와 한 번 조우하는 맵 하나 |
| 스테이지 승리 | 몬스터를 **모두** 전투 불능으로 만듦 |
| 스테이지 패배 | 아군 **전원**이 전투 불능 |
| 레벨 디자인 | 9개 맵을 따로 디자인 ([로드맵 M5](ROADMAP.md#8-m5-콘텐츠-기획)) |

### 2-2. 흐름 ✅

```mermaid
flowchart TD
    A[막 시작<br/>전원 최대 HP · 부활 · 스킬 횟수 회복] --> B[스테이지 전투]
    B -- 승리 --> C[보상 화면<br/>드랍 아이템 확인]
    C --> D[정비<br/>드랍 나눠 주기 · 장비 교체 · 물약 주고받기]
    D --> E{막의 마지막 스테이지?}
    E -- 아니오 --> B
    E -- 예 --> F{3막?}
    F -- 아니오 --> A
    F -- 예 --> G[3막 졸업]
    B -- 전멸 --> H[막 재시작<br/>그 막의 1스테이지부터]
    H --> A
```

- 전멸하면 **그 막의 1스테이지부터** 다시 합니다.
- 막을 다시 시작해도 **그 막에서 얻은 장비는 유지**합니다.
- 물약은 일회성 소모품입니다. 쓴 물약은 막을 다시 시작해도 돌아오지 않고, 얻은 물약은 남습니다 (3-1).

### 2-3. 막별 적 강화 ✅

1막은 지금 적 수치 그대로입니다. 2막과 3막은 모든 적의 기본 수치에 아래 값을 더하거나 곱합니다. 막이 올라갈수록 좋아지는 장비(4-4)와 맞물리도록 정했습니다.

| 적 수치 | 1막 | 2막 | 3막 |
|---|---|---|---|
| 명중 | +0 | +2 | +5 |
| AC | +0 | +2 | +5 |
| 최대 HP | 그대로 | ×1.5 | ×2 |
| 피해 | +0 | +2 | +4 |

> 그 막의 장비를 중간 수치로 갖췄을 때 아군과 적의 명중률이 막마다 비슷하게 유지되고, 적 전사가 아군 전사를 쓰러뜨리는 데 평균 2번쯤 걸리도록 맞췄습니다. 손 계산 값이며 실제 플레이로 확인합니다 (M6).

## 3. 막 단위 자원

### 3-1. 자원표 ✅

| 자원 | 같은 막의 스테이지 사이 | 막 시작 | 막 재시작 (전멸) |
|---|---|---|---|
| HP | **이어짐** (회복 없음) | 전원 최대 HP | 전원 최대 HP |
| 전투 불능 | **이어짐**. 남은 스테이지에 나오지 않음 | 부활 | 부활 |
| 스킬 사용 횟수 | **이어짐** | 회복 | 회복 |
| 장비 | 유지 | 유지 | 유지 |
| 물약 | 유지 | 유지 | 지금 가진 개수 그대로 |

- 스킬 사용 횟수의 **값은 지금 그대로**입니다(숨 고르기 1, 흘려내기 2 등). 단위만 전투당에서 막당으로 바뀝니다. 횟수 조정은 스킬 디자인 때 정합니다 (5장).
- 물약은 **몬스터 드랍으로만** 얻습니다. 시작할 때는 없습니다.
- 물약은 **캐릭터별로** 가집니다. 전투에서는 자기 물약만 씁니다. 스테이지 사이 정비 단계에서 캐릭터끼리 주고받을 수 있습니다 (4-3).

### 3-2. 막 안에서 전투 불능 ✅

전투 불능이 된 캐릭터는 그 막의 남은 스테이지에 나오지 않습니다. 남은 캐릭터만으로 싸우고, 다음 막 시작에 최대 HP로 부활합니다.

> 파티가 2명이라 1스테이지에서 한 명이 쓰러지면 남은 2스테이지를 혼자 싸웁니다. 난이도는 레벨 디자인과 밸런스(M5, M6)에서 확인합니다.

## 4. 아이템

### 4-1. 장비 ✅

| 항목 | 결정 |
|---|---|
| 장착 칸 | 캐릭터마다 **무기 1, 방어구 1** |
| 무작위 수치 | 드랍될 때 성능 수치가 무작위로 정해짐. 같은 아이템도 수치가 달라 다시 얻을 이유가 됨 |
| 교체 시점 | **스테이지 사이마다** 정비 단계에서 (보상 화면 뒤) |
| 막 재시작 | 그 막에서 얻은 장비 유지 |

### 4-2. 드랍 ✅

| 항목 | 결정 |
|---|---|
| 보장 | 스테이지를 깨면 아이템 **1개 보장** |
| 추가 | 몬스터마다 확률로 추가 드랍 |
| 드랍 대상 | 장비(무기, 방어구)와 물약 |

보장 드랍이 있어 운이 나빠도 9전투에서 최소 9개를 얻습니다.

### 4-3. 정비 단계 ✅

스테이지 승리 뒤 보상 화면 다음에 오는 단계입니다.

| 항목 | 결정 |
|---|---|
| 드랍 나눠 주기 | 드랍된 아이템(장비, 물약)을 플레이어가 캐릭터에게 **나눠 줌** |
| 받지 않은 아이템 | 받지 않아도 됨. 정비 단계를 끝내면 **버려짐** |
| 장비 교체 | 캐릭터마다 무기·방어구를 바꿈. **교체로 빠진 장비는 버려짐**. 장착하지 않은 장비는 들고 다니지 않음 |
| 물약 주고받기 | 캐릭터끼리 물약을 넘김. **전투 불능인 캐릭터의 물약도** 다른 캐릭터에게 넘길 수 있음 |
| 물약 한도 | 캐릭터당 **3개**. 한도를 넘게 줄 수 없음 |
| 전투 불능인 캐릭터 | 아이템(장비, 물약)을 **받을 수 있음**. 다음 막에 부활하면 그 장비로 나옴 |

> 지금은 장비를 장착 칸에만 둡니다. 이후에는 RPG답게 얻은 아이템을 모두 보관하는 **전체 루팅**(인벤토리)으로 넓힐 계획입니다. 개발은 장비 보관을 나중에 인벤토리로 바꾸기 쉽게 만듭니다.

### 4-4. 아이템 종류와 수치 ✅

아이템은 **무기, 방어구, 회복 물약** 3종입니다. 장비는 두 수치를 가지며, 드랍될 때 각 수치를 **따로** 굴립니다. 범위는 아이템을 **얻은 막**의 범위를 씁니다.

| 아이템 | 수치 | 1막 | 2막 | 3막 |
|---|---|---|---|---|
| 무기 | 명중 | +1~2 | +3~4 | +5~7 |
| | 피해 | +1~3 | +4~6 | +7~10 |
| 방어구 | AC | +1~2 | +3~4 | +5~7 |
| | 최대 HP | +2~4 | +5~8 | +9~14 |
| 회복 물약 | 회복 | 2d4+2 | 2d4+2 | 2d4+2 |

- **막끼리 범위가 겹치지 않습니다.** 낮은 막에서 높은 막보다 좋은 수치가 나오지 않고, 높은 막에서 낮은 막의 수치가 나오지 않습니다.
- 같은 막 안에서도 두 수치가 따로 정해지므로 명중이 높은 무기와 피해가 높은 무기를 비교할 이유가 생깁니다.
- 장비 수치는 능력치를 바꾸지 않고 명중·피해·AC·최대 HP에 더합니다.

### 4-5. 드랍 확률 ✅

| 항목 | 결정 |
|---|---|
| 추첨 비중 | 무기 **2**, 방어구 **2**, 회복 물약 **3** |
| 몬스터당 추가 드랍 | **35%** |
| 보장 드랍 풀 | 추가 드랍과 **같은 풀** |

> 스테이지마다 적이 2명이면 9전투에서 평균 약 15개(장비 약 9, 물약 약 7)를 얻습니다. 1막 3전투에서 물약을 하나도 못 얻을 확률은 약 7%입니다.

### 4-6. 최대 HP가 바뀔 때 현재 HP ✅

방어구를 장착·교체·해제해 최대 HP가 바뀌면 **잃은 HP를 유지**합니다.

- 최대 HP가 오르면 현재 HP도 같은 만큼 오릅니다. 예: HP 8/15에서 최대 HP +5 방어구를 끼면 13/20.
- 최대 HP가 내려가면 현재 HP도 같은 만큼 내려갑니다. 최소 1입니다.
- 장비를 바꿔 끼워 HP를 회복할 수 없습니다.
- 전투 불능 캐릭터는 방어구를 받아도 HP 0 그대로입니다. 아이템 수령은 부활·회복이 아닙니다 (4-3).

### 4-7. 보류한 것 ❓

| 항목 | 언제 |
|---|---|
| 등급 | M5 몬스터 기획과 함께 다시 봄. 막별 수치 상승이 등급 역할을 일부 대신함 |
| 직업 제한 | 직업과 스킬을 늘릴 때. 지금은 모든 캐릭터가 같은 무기·방어구를 씀 |
| 전체 루팅(인벤토리)으로 넓히는 시기와 보관 한도 | 미정 |

## 5. 캐릭터

| 항목 | 결정 |
|---|---|
| 파티 | 지금 그대로 전사 1, 궁수 1 ✅ |
| 역할 | **전사 = 탱커, 궁수 = 딜러** ✅ |
| 스킬 | 직업마다 스킬을 늘릴 수 있음. 스킬 디자인은 기획 담당이 정함 ❓ |

> 적 AI가 "사거리 안에서 HP가 낮은 대상"을 노리므로([전투 시스템 기획서 7장](COMBAT_DESIGN.md#7-적-ai)), 지금 규칙으로는 전사가 공격을 끌어 줄 수 없습니다. 탱커 스킬(도발 등)이나 적 AI 조준 규칙은 스킬 디자인과 함께 정합니다.

## 6. 헥사 격자

### 6-1. 결정 ✅

| 항목 | 결정 |
|---|---|
| 타일 | 육각형, **뾰족한 위(pointy-top)** |
| 맵 크기와 모양 | 직사각형 배치, 10열 × 10행 = 100칸 |
| 타일 픽셀 크기 | 20×20px |
| 인접 | 6칸 |
| 거리 | 헥사 거리. 이동력과 사거리는 헥사 칸 수로 셈 |
| 수치 | 이동력 6칸, 궁수 사거리 1~6칸 그대로 |

### 6-2. 시안 확인 결과와 남은 확인

- ✅ 2026-10-08 기획자가 현재 헥사 타일 시안을 승인했습니다. 직사각형100칸과20×20px를 채택합니다([Issue #53 승인 기록](https://github.com/minjunkim-dev/BGLike/issues/53#issuecomment-6052407365)). 기준 해상도640×360과 정수 배율은 유지합니다.
- ❓ 궁수 사거리6이 맵 크기에 맞는지는 별도 플레이 확인이 남습니다. 현재 시안의 최대 헥사 거리는14칸입니다. 예전 사각 격자의 최대 거리9칸을 현재 사거리 적합성의 근거로 사용하지 않습니다.

## 7. 전투 시스템 기획서에서 바뀌는 규칙

[전투 시스템 기획서](COMBAT_DESIGN.md)의 아래 내용을 이 문서로 대체합니다. 나머지 규칙은 그대로입니다.

| 기획서 위치 | 지금 | 바뀜 |
|---|---|---|
| 2장 맵 | 10×10 아이소메트릭 격자 | 헥사 격자 (6장) |
| 2장 궁수 사거리 근거 | 10×10에서 가장 먼 거리 9칸 | 헥사 맵에서 다시 확인 (6-2) |
| 5-2 기회 공격 | 인접 칸(8칸)을 벗어날 때 | 인접 칸(**6칸**)을 벗어날 때 |
| 5-3 스킬 | 모든 스킬 횟수는 **전투당** | 모든 스킬 횟수는 **막당**. 값은 그대로 |
| 5-4 물약 | 유닛당 1개 | 몬스터 드랍으로 얻는 일회성 소모품. 캐릭터별 보유, 시작 개수 0 |
| 5-4 밀치기 방향 | 밀치는 유닛 → 대상 방향(8방향) | 밀치는 유닛 → 대상 방향(**6방향**). 인접한 대상이라 방향이 항상 하나로 정해짐 |
| 9-3 동작 설명 | 전투당 남은 횟수 | 막당 남은 횟수 |
| 9-4 이동 미리보기 | 사각 격자 칸 | 헥사 칸. 표시 규칙은 그대로 |

"전투가 끝날 때까지" 유지되는 효과(표식 등)는 그대로 전투 단위입니다.

## 8. 정해야 할 것

|---|---|---|
| 아이템 등급, 직업 제한, 인벤토리 (4-7) | 기획 | M5 이후 |
| 스킬 추가와 횟수, 탱커 수단 (5장) | 기획 | 스킬 디자인 |
| 궁수 사거리6의 헥사 맵 적합성 (6-2) | 기획 | 별도 플레이 확인 |
| 몬스터 종류 | 기획 | M5. 그 전까지 지금의 적 전사·궁수를 씀 |
| 9개 스테이지 레벨 디자인 | 기획 | M5. 그 전까지 지금 시험 전투를 반복 |
| 저장 (게임을 껐다 켤 때) | 기획 | M7 |
