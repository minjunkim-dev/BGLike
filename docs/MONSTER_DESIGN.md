## 1. 이 문서를 쓰는 법

- 새 몬스터를 기획할 때 일반 몬스터는 5장, 보스는 7-2의 시트를 복사해 채웁니다.
- 시트의 수치와 규칙이 정해지면 전투 시스템 기획서나 게임 구조 기획서로 옮깁니다. 이 문서에는 컨셉, 장단점, 던지는 질문처럼 **왜 그렇게 만들었는지**를 남깁니다.
- 세계관과 이야기는 M7에서 정합니다. 그 전까지 이름은 역할을 드러내는 가칭을 씁니다.

## 2. 디자인 원칙

| 원칙 | 상태 | 내용 |
|---|---|---|
| 컨셉 필수 | ✅ | 모든 몬스터는 컨셉을 가집니다. 컨셉이 스킬과 수치를 정하는 기준입니다 |
| 추상 컨셉 없음 | ✅ | 몬스터는 캐릭터와 달리 소설 같은 추상 컨셉을 쓰지 않습니다. 컨셉은 "무엇을 하는 몬스터인가"를 적은 한 줄입니다 (2026-10-13) |
| 장단점 필수 | ✅ | 모든 몬스터는 장점과 단점을 함께 가집니다. 단점이 없는 몬스터는 만들지 않습니다 |
| 질문 하나 | 🟡 | 몬스터 하나는 플레이어에게 전술 질문 하나를 던집니다. 예: "누구부터 잡을까?", "어디에 설까?" |
| 기존 동작 재사용 | 🟡 | 새 규칙보다 기존 동작(기절, 밀치기, 기회 공격, 유리/불리, 내성 굴림)의 조합을 먼저 찾습니다 |
| 대응 수단 | 🟡 | 몬스터의 장점마다 그것을 받아칠 아군 수단이 하나 이상 있어야 합니다 |

## 3. 등급 ✅

몬스터를 강한 정도로 나눕니다. 지금은 두 등급만 둡니다.

| 등급 | 뜻 | 추가 항목 |
|---|---|---|
| 일반 | 스테이지에 여럿 나오는 기본 몬스터 | 없음 |
| 보스 | 강한 몬스터. 일반 몬스터보다 확실히 강함 | 7장의 높은 체력, 패배 조건, 패턴, 기믹 |

- 그 사이 등급(예: 정예)은 필요해지면 다시 논의합니다 ❓.
- 아이템 등급과는 별개입니다. 아이템 등급은 [게임 구조 기획서 4-7](GAME_STRUCTURE.md#4-7-보류한-것-)에서 보류 중입니다.

## 4. 역할 🟡

몬스터는 위치에 따른 역할을 적습니다. 캐릭터의 역할(탱커, 딜러, 서포터)과는 다른 분류입니다.

| 역할 | 예 |
|---|---|
| 근접 | 지금의 적 전사 |
| 원거리 | 지금의 적 궁수 |
| 지원 | 동료 회복·강화, 아군 약화 ❓ |

| 항목 | 내용 |
|---|---|
| 이름 | 가칭 |
| 등급 | 일반 |
| 컨셉 | "무엇을 하는 몬스터인가" 한 줄 |
| 역할 | 근접 / 원거리 / 지원 |

| 단점 | 1~2개. 플레이어가 화면에서 알아챌 수 있어야 함 |
| 던지는 질문 | 이 몬스터가 나오면 플레이어가 고민할 것 |
| 대응 수단 | 장점을 받아칠 아군 스킬·동작 |

| 전투 수치 | HP, AC, 이동력 |
| 기본 공격 | 근접/원거리, 공격 능력치, 피해, 사거리, 기회 공격 가능 여부 |
| 스킬 | 이름, 소비 자원(행동/보조 행동/반응), 횟수, 대상, 효과 |
| AI | 우선 대상, 이동 방식, 스킬 쓰는 조건 |
| 등장 막 | 1 / 2 / 3. 막별 적 강화는 [게임 구조 기획서 2-3](GAME_STRUCTURE.md#2-3-막별-적-강화-)을 따름 |
| 드랍 | 기본은 몬스터당 추가 드랍 35% ([게임 구조 기획서 4-5](GAME_STRUCTURE.md#4-5-드랍-확률-)) |
| 외형 메모 | 실루엣과 색만. 에셋 출처는 M2 사용자 타겟 뒤에 정함 ❓ |

## 6. 지금 몬스터

지금 적은 아군과 같은 전사와 궁수를 씁니다 ([게임 구조 기획서 8장](GAME_STRUCTURE.md#8-정해야-할-것)). 둘 다 **일반** 등급입니다.

- 기본 수치와 스킬은 [전투 시스템 기획서 2장·5장](COMBAT_DESIGN.md#2-시험-전투), AI는 [7장](COMBAT_DESIGN.md#7-적-ai), 막별 강화는 [게임 구조 기획서 2-3](GAME_STRUCTURE.md#2-3-막별-적-강화-)이 기준입니다. 2026-10-13 `main`의 구현(`scenes/combat/unit.gd`, `enemy_ai.gd`)과 같은 값입니다.
- 적은 장비를 끼지 않습니다. 물약은 없고(0개), 밀치기는 AI가 쓰지 않습니다.
- 스킬 횟수는 막당이지만, 적은 스테이지마다 새로 나오므로 스테이지마다 다시 채워집니다.
- 던지는 질문과 대응 수단은 제안입니다 🟡.

### 6-1. 적 전사

| 항목 | 내용 |
|---|---|
| 등급 / 역할 | 일반 / 근접 |
| 컨셉 | 앞에서 버티다 붙은 상대를 몰아치는 근접 병사 |
| 장점 | 높은 AC. 흘려내기로 명중을 피함. 기회 공격으로 아군의 이동을 막음. 몰아치기로 한 턴에 두 번 공격 |
| 단점 | 사거리가 인접뿐. 정신 −1이라 충격 화살 기절에 약함 |
| 던지는 질문 🟡 | 붙어서 받아칠까, 궁수로 멀리서 깎을까 |
| 대응 수단 🟡 | 충격 화살(정신 내성), 밀치기로 떼어 내기, 물러서며 쏘기 |

| 능력치 | 힘 | 민첩 | 건강 | 정신 | 이동력 |
|---|---|---|---|---|---|
| 보정값 | +3 | +1 | +2 | −1 | 6 |

| 기본 공격 | 공격 능력치 | 사거리 | 기회 공격 | 내성 DC |
|---|---|---|---|---|
| 근접 | 힘 | 1 (인접) | 가능 | 13 |

| 스킬 | 소비 | 횟수 | 효과 | AI가 쓰는 조건 |
|---|---|---|---|---|
| 숨 고르기 | 보조 행동 | 1 | HP `1d10+1` 회복 | 턴 시작에 HP가 절반 이하 |
| 흘려내기 | 반응 | 2 | 명중당하면 `d20 + 민첩 ≥ 공격자 내성 DC`로 그 공격을 피함 | 조건이 맞으면 항상 |
| 몰아치기 | 보조 행동 | 1 | 이미 쓴 행동을 다시 채움 | 공격 뒤에도 대상이 인접하고, 이번 턴에 숨 고르기를 쓰지 않음 |

### 6-2. 적 궁수

| 항목 | 내용 |
|---|---|
| 등급 / 역할 | 일반 / 원거리 |
| 컨셉 | 거리를 벌리며 표식한 상대를 기절시키는 사수 |
| 장점 | 사거리 1~6. 표식으로 한 대상에 피해를 몰아줌. 충격 화살로 기절. 물러서며 쏘기로 기회 공격 없이 빠짐 |
| 단점 | AC가 낮음. 아군이 붙으면 원거리 공격이 불리. 기회 공격을 하지 못함 |
| 던지는 질문 🟡 | 전사를 두고 궁수에게 먼저 달려갈까 |
| 대응 수단 🟡 | 전사로 붙어 불리 주기, 흘려내기(충격 화살의 기절도 피함), 기회 공격 |

| 능력치 | 힘 | 민첩 | 건강 | 정신 | 이동력 |
|---|---|---|---|---|---|
| 보정값 | +0 | +3 | +1 | +1 | 6 |

| 기본 공격 | 공격 능력치 | 사거리 | 기회 공격 | 내성 DC |
|---|---|---|---|---|
| 원거리 | 민첩 | 1~6 | 불가 | 13 |

| 스킬 | 소비 | 횟수 | 효과 | AI가 쓰는 조건 |
|---|---|---|---|---|
| 표식 | 보조 행동 | 1 | 전투가 끝날 때까지 이 대상을 맞히면 피해 `+1d6` | 첫 공격 전 |
| 충격 화살 | 행동 | 1 | 원거리 명중 판정. 명중하면 대상이 정신 내성(DC 13)에 실패할 때 기절 | 남아 있으면 기본 공격 대신 |
| 물러서며 쏘기 | 보조 행동 | 2 | 이번 턴의 남은 이동은 기회 공격을 받지 않음 | 인접한 상대가 있어 거리를 벌릴 때 |

### 6-3. 막별 수치

막별 적 강화를 더한 값입니다. 능력치, 이동력, 사거리, 스킬 횟수, 내성 DC(13)는 막이 바뀌어도 그대로입니다.

| 수치 | 적 전사 1막 | 2막 | 3막 | 적 궁수 1막 | 2막 | 3막 |
|---|---|---|---|---|---|---|
| 최대 HP | 12 | 18 | 24 | 14 | 21 | 28 |
| AC | 16 | 18 | 21 | 14 | 16 | 19 |
| 공격 보너스 | +5 | +7 | +10 | +5 | +7 | +10 |
| 피해 | 1d8+3 | 1d8+5 | 1d8+7 | 1d6+1 | 1d6+3 | 1d6+5 |

## 7. 보스 몬스터

### 7-1. 보스의 조건 ✅

보스는 일반 몬스터 시트(5장)를 모두 채우고, 아래 네 항목을 더합니다. 보스도 장점과 단점을 함께 가집니다.

| 항목 | 뜻 | 예 |
|---|---|---|
| 높은 체력 | 일반 몬스터보다 크게 높은 HP. 한두 턴에 쓰러지지 않아 패턴을 보여 줄 시간을 만듦 | 일반 몬스터 HP의 몇 배 ❓ |
| 패배 조건 | 보스를 쓰러뜨리는 방법이나 플레이어가 지는 조건 | HP 0 / 특정 오브젝트 파괴 / N턴 버티기 ❓ |
| 패턴 | 보스가 반복하는 행동 순서. 플레이어가 읽고 대비할 수 있어야 함 | 2턴마다 범위 공격, 다음 턴 행동 예고 |
| 기믹 | 그 보스에게만 있는 특수 규칙 | HP 50%에 단계 전환, 졸개 소환, 기절 1회 면역 |

### 7-2. 보스 시트

5장 시트에 아래를 더합니다.

| 항목 | 내용 |
|---|---|
| 등급 | 보스 |
| 장점 / 단점 | 단점은 공략의 실마리가 됨 |
| 높은 체력 | HP와 그 근거 |
| 패배 조건 | 보스 쪽, 아군 쪽 |
| 패턴 | 턴별 또는 조건별 행동표 |
| 기믹 | 특수 규칙과 화면에 알리는 방법 |
| 단계 | 단계가 있으면 전환 조건과 단계별 변화 |
| 등장 위치 | 막과 스테이지 |
| 보상 | 드랍 ❓ |

### 7-3. 기존 규칙과 부딪히는 점 ❓

보스를 만들기 전에 정해야 합니다.

| 기존 규칙 | 부딪히는 점 |
|---|---|
| 스테이지 승리 = 몬스터 전멸 ([게임 구조 기획서 2장](GAME_STRUCTURE.md#2-진행-구조)) | "오브젝트 파괴"나 "N턴 버티기" 같은 패배 조건을 쓰면 승리 조건에 예외가 생김 |
| 막별 적 강화(3막 최대 HP ×2) | 보스의 높은 체력에 강화를 또 곱할지 |
| 기절은 턴을 통째로 넘김 | 보스가 기절하면 패턴이 끊김. 면역이나 저항이 필요한지 |
| 적 AI는 공통 규칙 + 유닛별 규칙 | 패턴과 단계는 지금 AI 구조보다 복잡함 |
| 스킬 횟수는 막당 | 보스전 앞에서 스킬을 아끼게 되는지 |

## 8. 새 몬스터 체크리스트

- [ ] 한 줄 컨셉이 있다.
- [ ] 장점과 단점이 모두 있고, 단점이 화면에서 보인다.
- [ ] 등급과 역할이 정해졌다.
- [ ] 던지는 질문과 대응 수단이 있다.
- [ ] 보스라면 높은 체력, 패배 조건, 패턴, 기믹을 모두 채웠다.
- [ ] 새 규칙이 필요하면 무엇인지 적고 Issue에 질문을 남겼다.
- [ ] 이름과 텍스트에 BG3 고유 명칭을 쓰지 않았다.

## 9. 추가 논의할 것

| 주제 | 질문 |
|---|---|
| 몬스터 수 | 막당 2~3종 + 보스로 갈까 (2026-10-13 논의에서 방향으로 이야기함, 미확정) |
| 보스 수와 위치 | 막마다 마지막 스테이지에 보스 / 3막에만 보스 |
| 중간 등급 | 일반과 보스 사이 등급이 필요한가 |
| 막별 강화 | 새 몬스터의 기본 수치를 1막 기준으로 잡고 강화를 그대로 적용할까 |
| 스테이지당 적 수 | 지금 2명. 떼로 나오는 몬스터를 넣으려면 늘려야 함. 레벨 디자인과 함께 정함 |
| 드랍 | 보스나 강한 몬스터의 드랍 확률과 보장 아이템 |
| 정신 보정값 | 몬스터마다 정신을 달리해 기절·도발 내성으로 성격을 줄까 |
| 외형과 이름 | 세계관(M7)과 에셋 출처(M2) 결정 뒤 |
