## 0. 개정 후속 요청 (2026-10-27)

### 0-1. 목표

**공격·효과 판정을 "공격자 대 방어자 주사위 대결"에서 BG3 구조의 명중굴림(공격자 굴림 대 AC)과 내성굴림(대상 굴림 대 DC)으로 바꾸고, 능력치 구성을 힘, 민첩, 솜씨, 지능, 의지, 건강으로 개편합니다.** 피해는 능력치 주사위로 굴리고, 모든 주사위에 절대면을 둡니다.

| 확인하려는 것 | 확인하지 않는 것 |
|---|---|
| 굴림 한 번과 고정 AC로 읽기 쉬운 판정, 화면 확률이 실제 확률과 같은지 | 밸런스 (몬스터·장비 값은 시험용) |
| 내성굴림으로 바뀐 광역·상태 효과가 대상마다 굴려지는 흐름 | 능력치 성장(주사위 레벨), 절대성공면 획득 |
| 능력치 주사위로 굴리는 피해의 규모 | 새 스킬·직업 |
| 모양 차이가 AC·DC 앞에서 만드는 직업 차이 | 연출, 아트 |

### 0-2. 만들 것

자세한 규칙은 기획서의 해당 절을 봅니다. **필수**는 빠지면 목표를 이룰 수 없는 항목입니다.

| 항목 | 기획서 | 우선순위 |
|---|---|---|
| 능력치 개편: 자연 → 건강(정의·독 내성·UI 표기), 직업 주사위 값, 몬스터 시험값 | 3, 6, 7장 | 필수 |
| 판정 엔진: 명중굴림(공격 굴림 ≥ AC), 내성굴림(내성 굴림 ≥ DC), 표준값, 방어자 굴림 제거, "이상이면 성공" | 4-1, 4-3 | 필수 |
| AC·DC 데이터: AC = 민첩 표준값 + 방어 가산(직접 지정 덮어쓰기 가능), DC = 시전 능력치 표준값 + 공격 가산(+스킬 DC 보정), 잔류 효과의 DC 기록 | 4-3, [동작 유형 4-2](SKILL_TYPES.md#4-2-명중굴림과-내성굴림-) | 필수 |
| 광역·효과 이관: 대상마다 내성굴림, 시전자는 DC만, 내성 성공 시 피해 절반(내림, 최소 1)·상태 무효, 공통 공격 굴림과 혼합 유리 규칙([#341](https://github.com/minjunkim-dev/BGLike/issues/341)) 정리 | 4-1, 4-4 | 필수 |
| 피해: 능력치 주사위 + 기타 가산치, 명중하면 새로 굴림, 광역은 대상마다 굴림, 스킬이 피해 능력치를 지정할 수 있는 구조(기본은 명중과 같음), `damage_sides` 제거와 몬스터 환산 | 4-9, 7장 | 필수 |
| 유리/불리: 굴림별 요인 수 비교, 명중굴림·내성굴림 모두 적용, 크기 무시 | 4-7 | 필수 |
| 절대면: 모든 주사위의 절대실패면 1개, d12의 절대성공면 1개, d20의 절대성공면 3개(시작, 절대성공면은 시험용 임시), 판정 효과, 숫자 취급(최댓값·1)을 표준값·유리/불리 선택·피해 굴림에 반영. **획득·성장은 제외** | 4-11 | 필수 |
| 이니셔티브: 몬스터도 민첩 주사위 | 4-8 | 필수 |
| 기존 동작 이관: 기본 공격·기회 공격, 밀치기·만능팔·회전회오리(힘 내성), 충격 화살, 흘려내기, 독 중첩 제거(건강 내성, 고정 DC 4). **궁수의 기본 공격·충격 화살은 임시로 솜씨** | 8장 | 필수 |
| 미리보기·로그·UI: 명중굴림·내성굴림 확률(면 열거, 유리/불리·절대면·가산 반영), 유닛 패널의 AC와 능력치 모양, 건강 표기 | 4-10 | 필수 |
| 장비 데이터 의미: `attack_bonus`(공격 가산, DC에도 가산), `armor_class`(방어 가산, AC·내성굴림에 가산)와 정비 화면 문구 | 4-6 | 필수 |
| 저장 형식 버전 올림 ([ADR-0003](adr/0003-save-files.md)): 건강, 절대면, 몬스터 값 | — | 필수 |

### 0-3. 만들지 않을 것

| 항목 | 이유 |

| 치명타 재도입, 절대성공의 추가 이점 | 나중에 다룸. 지금은 비활성 |
| 최대 HP 식(직업 기본값 + 건강 면수 ÷ 2 + 레벨 × m)의 값, 회복량의 건강 연동 | 식의 구조는 정함. 직업 기본값과 m은 수치 설계 때 정함 (4-9). 이동력은 능력치와 연동하지 않음 |
| 무기별 능력치 배정 변경 | 무기 기획 때 정함. 지금은 현행 지정을 유지. 단 궁수의 기본 공격·충격 화살은 임시로 솜씨로 바꿈 |
| 스킬별 내성 능력치 재설계 | 스킬을 만들거나 고칠 때 정함. 기존 동작은 현행 능력치(힘)를 유지 |
| 속성(피해 유형) 시스템, 새 직업·새 스킬 | 후속 기획 |
| 몬스터·장비의 밸런스 조정 | [#205](https://github.com/minjunkim-dev/BGLike/issues/205) |

### 0-4. 개발 결정 후보

- 능력치 식별자 이름은 개발 담당이 정합니다. 기획에서 알리는 것은 **민첩은 Agility이며 Dexterity가 아니라는 뜻**뿐입니다.
- 표준값과 절대면을 가진 주사위 값의 표현, 면 열거 확률 계산의 확장 방식
- 시전 때 DC를 기록하는 데이터, 잔류 효과의 DC 보존
- 광역 혼합 유리 코드([#341](https://github.com/minjunkim-dev/BGLike/issues/341))의 정리 방식
- 저장 데이터에 건강과 절대면을 보존하는 모양
- 성장은 만들지 않지만, 굴림 값과 표준값 계산은 "주사위 눈 + 주사위 레벨"(레벨은 0에서 시작하고 6개 능력치와 모든 캐릭터가 공유하는 파티 값 하나) 구조로 정해졌으며, 별도 개발 요청 전까지 구현하지 않음 ([주사위 육성 논의 4장](DICE_GROWTH.md#4-주사위-레벨))

### 0-5. 기획 검수 기준

기획 담당이 아래 상황을 직접 만들어 확인합니다. 아래 체크박스는 사람의 직접 기획 검수용이며 에이전트의 자동 검사·실행 검수 결과로 대신 체크하지 않습니다.

#### 판정

- [ ] 전사가 풋내기 야만인(AC 4)을 근접 공격하면 미리보기 명중률이 **85.0%**로 나오고, 로그에 전사의 힘 d20 굴림 하나와 AC가 보인다. 야만인의 굴림은 없다.
- [ ] 풋내기 야만인이 전사를 공격하면 야만인의 굴림 하나와 전사의 AC(5)가 보이고, 전사 명중률 90.0%, 궁수(AC 7) 70.0%로 표시된다.
- [ ] 궁수가 풋내기 야만인(AC 4)을 쏘면 솜씨 d20 굴림 하나로 판정하고 미리보기 명중률이 **85.0%**로 나온다.
- [ ] 전사의 힘 d20에서 절대성공면(20)이 나오면 AC와 무관하게 명중하고, 절대실패면(1)이 나오면 가산이 있어도 빗나간다.
- [ ] 같은 모양 주사위와 가산 0이면 명중굴림과 내성굴림 성공률이 모두 50%이다.
- [ ] 장비 공격 가산 +1은 공격 굴림과 DC에, 방어 가산 +1은 AC와 내성굴림에 더해지고 미리보기 확률에 반영된다.
- [ ] 표식, 숨 고르기, 물약처럼 판정이 없는 동작은 굴림 없이 동작한다.
- [ ] 유리 요인이 있으면 굴림이 두 번 보이고 높은 값을 쓴다. 유리와 불리 요인 수가 같으면 일반 한 번이다. 요인이 여러 개여도 두 번만 굴린다.
- [ ] 치명타·자동 실패 팝업과 문구가 나오지 않는다.

#### 피해

- [ ] 피해는 공격 능력치 주사위를 새로 굴린 값 + 가산치이다. 명중굴림에서 나온 값과 무관하다.

#### 광역과 효과

- [ ] 고철로봇-3000의 회전회오리는 시전자 굴림 없이, 맞는 대상마다 힘 내성굴림을 하고(DC 10) 성공하면 피해가 절반(내림, 최소 1)이다. 전사 55%, 궁수 0%로 표시된다.

#### 임시 규칙

- [ ] 충격 화살은 명중굴림 하나만 하고, 명중하면 기절을 건다. 기절용 내성굴림은 없다. 기절 면역 보스는 기절하지 않는다.
- [ ] 흘려내기는 전사의 민첩 주사위 + 3이 맞은 공격의 공격 굴림 이상이면 성공한다 (풋내기 야만인 상대 약 39%).
- [ ] 독 중첩 제거는 건강 내성굴림이 DC 4 이상이면 가장 오래된 독 하나를 제거한다 (전사 75%, 궁수 62.5%).

#### 능력치와 화면

- [ ] 유닛 패널에 능력치 6종(힘, 민첩, 솜씨, 지능, 의지, 건강)의 모양과 AC가 보이고 자연은 없다. HP는 수치로 남는다.
- [ ] 이니셔티브는 민첩 주사위로 정해지고 턴 순서 바 호버에 주사위가 보인다.

#### 저장·문서

- [ ] 옛 저장 파일은 읽지 않고, 새 저장은 이어하기가 된다 (형식 버전).
- [ ] 기획서 10장의 문서가 이 규칙과 일치한다.

> 아래 1~8장은 개정 전 요청(주사위 대결)의 기록입니다. 개정 규칙과 다른 곳은 0장이 우선합니다.

## 1. 목표

**공격과 효과의 판정을 d20 + 보정값에서 능력치 주사위 대결로 바꾸고, 능력치를 6종(힘, 민첩, 솜씨, 지능, 의지, 자연)으로 개편합니다.**

| 확인하려는 것 | 확인하지 않는 것 |
|---|---|
| 공격자 주사위 대 방어자 주사위 대결의 손맛 | 밸런스 (몬스터 값은 시험용) |
| 무기·스킬·효과가 지정하는 능력치로 판정이 이어지는 구조 | 능력치 성장, 면 업그레이드 |
| 모양(d4~d20)이 만드는 직업의 상성 (힘 방어는 원거리에 약함 등) | 새 스킬·직업 |
| 화면의 명중률이 실제 확률과 같은지 | 연출, 아트 |

| 표시 확률 | [#220](https://github.com/minjunkim-dev/BGLike/issues/220) 결정 유지. 보정 없이 실제 확률 |
| 수치 | 몬스터와 장비 값은 시험용. 조정은 [#205](https://github.com/minjunkim-dev/BGLike/issues/205) |
| 육성 | 능력치 성장·면 업그레이드는 만들지 않음 |

## 4. 만들 것

자세한 규칙은 기획서의 해당 절을 봅니다. **필수**는 빠지면 목표를 이룰 수 없는 항목입니다.

| 항목 | 기획서 | 우선순위 |
|---|---|---|
| 능력치 주사위 데이터: 6종, 모양, 면(`1~n`), 전사·궁수·몬스터 정의 | 3, 6, 7장 | 필수 |
| 판정 엔진: 공격 굴림 대 방어 굴림, 장비 가산, 동점 방어자 승, 판정 없는 동작 | 4-1, 4-5, 4-6 | 필수 |
| 공격·방어 능력치 연결: 무기·스킬이 지정하는 공격 능력치, 공격 거리 유형, 효과가 지정하는 방어 능력치 | 4-2, 4-3 | 필수 |
| 기존 동작 이관: 기본 공격, 기회 공격, 밀치기, 만능팔 | 8장 | 필수 |
| 광역 이관: 회전회오리를 "공격자 한 번 굴림 대 대상마다 방어 굴림"으로 | 4-4, 8장 | 필수 |
| 유리/불리, 이니셔티브 | 4-7, 4-8 | 필수 |
| 명중률 미리보기(면 조합 열거, 유리/불리·장비 가산 반영), 로그, 팝업 문구 | 4-9 | 필수 |
| 유닛 패널과 호버: 능력치 6종의 모양 표시, 건강·정신 삭제, "AC" → "방어" | 2장 | 필수 |
| 장비 데이터 의미 이관(`attack_bonus` → 공격 가산, `armor_class` → 방어 가산)과 정비 화면 비교 문구 | 4-6 | 필수 |
| 저장 형식 버전 올림 ([ADR-0003](adr/0003-save-files.md)) | 2장 | 필수 |
| 치명타·자동 실패 임시 비활성 | 4-10 | 필수 |
| 문서 동기화 | 10장 | 필수 |
| 충격 화살(민첩 하나만 비교), 흘려내기(방어 가산 +3), 독 중첩 제거(고정 강도 4, 자연)의 새 판정 | 8장 | 필수 |

## 6. 개발 결정 후보

아래는 요청 당시의 후보입니다. 선택한 방식과 근거는 [#321](https://github.com/minjunkim-dev/BGLike/issues/321)과 [기획서의 구현 개발 결정](ABILITY_SYSTEM.md#구현의-개발-결정-321)에 기록했습니다.

- 코드 식별자. 제안: `STRENGTH`, `DEXTERITY`, `CRAFT`(솜씨), `INTELLIGENCE`, `WILL`(의지), `NATURE`. "스킬(Skill)"과 겹치는 이름은 피함
- 능력치 주사위 값 객체의 설계와 `CombatDice`의 확장 방식
- 테스트 어댑터(`tests/scripted_dice.gd`)와 기존 회귀 검사의 고치는 방식
- 능력치 모양을 화면에 보이는 방식 (예: `힘 d20`)
- 로그 문구. 제안: `공격(근접): 힘 d20 12 대 힘 d10 6 · 명중`
- 이니셔티브 동점 처리 구현, 저장 데이터의 모양

## 7. 기획 검수 기준

기획 담당이 아래 상황을 직접 만들어 확인합니다. 아래 체크박스는 사람의 직접 기획 검수용이며 에이전트의 자동 검사·실행 검수 결과로 대신 체크하지 않습니다. 구현과 에이전트 검수 근거는 문서 상단의 #321·#307을 따릅니다.

### 판정

- [ ] 전사가 풋내기 야만인을 근접 공격하면 미리보기 명중률이 **72.5%**로 나오고, 로그에 두 주사위(전사 힘 d20, 야만인 힘 d10)가 보인다.
- [ ] 궁수가 인접한 적을 쏴도 방어 굴림은 민첩이다.
- [ ] 두 굴림이 같으면 방어자가 이긴다.
- [ ] 장비 공격 가산 +1은 공격 굴림에, 방어 가산 +1은 방어 굴림에 더해지고 미리보기 확률에 반영된다.
- [ ] 표식, 새끼 낳기, 숨 고르기, 물약처럼 판정이 없는 동작은 굴림 없이 동작한다.
- [ ] 유리/불리가 적용되면 공격자 주사위 두 개가 로그에 보이고 확률에 반영된다.
- [ ] 치명타·자동 실패 팝업과 문구가 나오지 않는다.

### 광역

- [ ] 고철로봇-3000의 회전회오리는 공격 굴림을 한 번만 보이고 대상마다 방어 굴림과 비교한다.

### 임시 규칙

- [ ] 충격 화살은 민첩 하나만 비교하고, 명중하면 기절을 건다. 기절용 방어 굴림은 없다. 기절 면역 보스는 기절하지 않는다.
- [ ] 흘려내기는 전사의 민첩 주사위 + 3이 맞은 공격의 공격 굴림 이상이면 성공한다. 풋내기 야만인 상대 성공률이 약 45%로 표시된다.
- [ ] 독 중첩 제거는 대상의 자연 주사위가 독 장판의 고정 강도(4) 이상이면 가장 오래된 독 하나를 제거한다 (전사·궁수 50%).

### 능력치와 화면

- [ ] 유닛 패널에 능력치 6종의 모양이 보이고 건강·정신은 없다. HP는 수치로 남는다.
- [ ] 장비와 정비 화면의 "AC" 표기가 "방어"로 바뀐다.
- [ ] 이니셔티브는 민첩 주사위로 정해지고 턴 순서 바 호버에 주사위가 보인다.

### 저장

- [ ] 옛 저장 파일은 읽지 않고, 새 저장은 이어하기가 된다 (형식 버전).

### 문서

- [ ] 10장의 문서가 이 규칙과 일치한다.
