## 2. 판정 후보 3안 비교

### 공통 전제

- 칸은 정사각형이고 거리는 `가로 차 + 세로 차`입니다. 이동은 4방향입니다.
- 차단 대상은 [환경요소 2-2](environment.md#2-2-공격시선파괴)의 박스·바위·벽·집·나무입니다. 유닛 차단은 11/18에 정합니다.
- 곡사는 경로를 보지 않는 현재 규칙에서 출발하고, 곡사의 엄폐 취급은 11/18에 정합니다.
- 비교는 공격자 칸 A에서 대상 칸 T로 가는 경로를 어떻게 정하느냐입니다.

### 후보

| 안 | 정의 | 결과 |
|---|---|---|
| ① 중심 선분 | A의 중심에서 T의 중심까지 선분을 긋고, 지나가는 칸(A·T 제외)에 차단 대상이 있는지 봅니다. | 막힘 / 안 막힘 (2단계) |
| ② 모서리 | A의 중심에서 T의 네 모서리로 선분 4개를 긋고, 몇 개가 막히는지 봅니다. | 4개 안 막힘 / 일부 막힘 / 전부 막힘 (3단계) |
| ③ 타일 통과 | A에서 T까지 격자 위 칸 경로(브레젠험 등)를 하나 정하고, 그 칸들을 봅니다. | 막힘 / 안 막힘 (2단계) |

### 기준별 비교

| 기준 | ① 중심 선분 | ② 모서리 | ③ 타일 통과 |
|---|---|---|---|
| 플레이어가 눈으로 예측 | 쉬움. 선분을 그려 보여 줄 수 있음 | 보통. 선분이 4개라 표시가 복잡함 | 어려움. 경로가 알고리즘에 따라 달라 직관과 어긋남 |
| 반엄폐(불리) 확장 | 선분이 칸 가장자리에 걸릴 때만 반 단계를 둘 수 있음 | 막힌 선분 수로 바로 나옴 | 어려움 |
| 대칭성(A→T와 T→A 결과 같음) | 같음 | 같지 않음(출발점이 중심, 도착이 모서리) | 알고리즘에 따라 다름 |
| 정확히 모서리를 지나는 경우 | 규칙이 필요함(아래 대각선 규칙) | 해당 없음 | 알고리즘이 정함 |
| 테스트 케이스 작성 | 좌표만 있으면 계산이 정해짐 | 좌표만 있으면 계산이 정해짐. 케이스 수가 많음 | 알고리즘 설명이 케이스에 같이 필요함 |
| 구현 난이도 | 낮음 | 보통 | 낮음 |
| 최소판(전엄폐만) 대응 | 그대로 쓸 수 있음 | "전부 막힘"만 쓰면 됨 | 그대로 쓸 수 있음 |

### 예시

공격자 A(0,0), 대상 T(4,1), 좌표는 (가로, 세로)입니다. ① 중심 선분이 지나는 칸은 (1,0), (2,0), (2,1), (3,1)입니다.

| 차단 대상 위치 | ① 중심 선분 | 직관 |
|---|---|---|
| (2,1) | 막힘 | 대각선 경로가 지나는 칸이라 막힘이 자연스러움 |
| (3,0) | 안 막힘 | 선분이 지나지 않는 칸 |
| (2,0)와 (2,1) 둘 다 | 막힘 | – |

정확히 칸 모서리를 지나는 경우는 ①에서 규칙이 필요합니다. 예를 들어 A(0,0)에서 T(3,1)로 가는 선분은 두 칸 (1,0)과 (2,1)을 지나며, 이 둘이 만나는 모서리 점을 정확히 통과합니다. 그 점에 닿기만 하는 칸 (2,0)과 (1,1)이 막혔을 때 선분이 막히는지가 애매합니다. 닿기만 하는 칸 하나가 막힌 경우는 막지 않고, 둘 다 막혔을 때만 막는 규칙을 권장합니다(모서리 틈으로 지나갈 수 있어야 4방향 격자에서의 대각선 감각과 맞습니다). 확정은 11/17에 합니다.

### 권장

**① 중심 선분**을 권장합니다. 일정 문서의 권장 후보와 같고 이유는 다음과 같습니다.

- 플레이어가 선분을 눈으로 따라가 예측할 수 있고, UI 미리보기(11/20)에서 그대로 그릴 수 있습니다.
- 대칭이고 좌표만으로 결과가 정해져 테스트 케이스 20개(11/19)를 만들기 쉽습니다.
- 최소판(전엄폐)으로 줄여도 같은 정의를 유지합니다([일정 5장](../../planning/schedule-2026-q4.md#5-일정이-밀릴-때)).
- 반엄폐가 필요해지면 ②의 "선분 여러 개" 아이디어를 ①의 확장으로 더할 수 있도록, 판정 함수의 결과를 막힘/안 막힘이 아닌 **막힌 정도**로 돌려주는 구조로 씁니다.

반대 의견: 반엄폐를 처음부터 넣을 계획이면 ②가 더 단순합니다. 일정상 반엄폐가 뒤로 밀리면 ①을 씁니다.

## 3. 11/17에 정할 것

1. 3안 중 확정(권장: ①)과 모서리를 지나는 경우의 규칙.
2. "뒤"의 정의: 대상이 차단 대상 바로 뒤여야 하는지, 선분 위 어디든인지.
3. 높이와의 관계: 지금은 "높이로 원거리 공격을 막지 않음"입니다. 높은 쪽 공격자·낮은 쪽 대상일 때 엄폐를 얼마나 인정할지.
4. 환경요소 2-2 시선 차단 열 확정(바뀐 부분은 11/20 요청서에 포함).
5. 1장 표의 11/17 항목 문장 갱신.
