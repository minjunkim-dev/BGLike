# 주사위 굴림 연출 기본값

[Issue #306](https://github.com/minjunkim-dev/BGLike/issues/306)의 [기획자 답변](https://github.com/minjunkim-dev/BGLike/issues/306#issuecomment-6406245423)에서 시작한 주사위 연출 기획이다. 굴림의 종류별로 연출 기본값을 정한다. 2026-10-31 기획자와 개발 논의 결과를 기록한다. 아직 구현하지 않았다.

## 시점과 범위

- M7에는 넣지 않는다. M6에서 만든다.
- 전투 중 굴림이 대상이다. 전투 밖 보상 추첨(`loot.gd`)은 이번 범위가 아니다.
- 기획자 후보 8개 연출 유형 중 이번에 쓰는 것은 아래다.

| 유형 | 내용 | 이번 사용 |
|---|---|---|
| 1 | 아무 연출 없음 | 사용 |
| 2 | 굴림 사운드 | 사용 |
| 3 | 성공/실패 애니메이션 | 사용 (숫자 + 색상) |
| 4 | 성공/실패 사운드 | 사용 |
| 5 | 굴림 애니메이션 | 사용 |
| 6 | n회 굴림 애니메이션 | 사용 (유리·불리) |
| 7·8 | 굴림 대결 애니메이션·승패 사운드 | 보류 |

## 굴림 카테고리와 기본값

굴림을 스킬 이름이 아니라 성격으로 나눈다. 새 스킬은 카테고리를 고르면 연출이 정해진다.

| 카테고리 | 성격 | 현재 굴림 | 연출 |
|---|---|---|---|
| 명중 | 공격 굴림 대 AC | 일반 공격, 기회 공격 등 | 애니메이션 + 굴림음 + 결과음 |
| 내성 | 굴림 대 정해진 기준값 | 흘려내기, 독 제거 | 애니메이션 + 굴림음 + 결과음 |
| 대결 | 양쪽이 굴려 총합 비교 | 만능팔, 밀치기, 회전회오리 방어 | **보류** |
| 피해 | 피해량 주사위 | 무기 피해, 표식 d6, 상자 피해, 화상 틱 | 없음(유형 1) |
| 회복 | 회복량 주사위 | 숨 고르기, 물약 | 없음(유형 1) |
| 이니셔티브 | 턴 순서 | 전투 시작 굴림 | 없음(유형 1) |
| 무작위 선택 | 후보 중 하나 고르기 | 소환 칸, 착지 칸 | 없음(유형 1) |

- 회전회오리의 방어는 내성굴림 티켓([#389](https://github.com/minjunkim-dev/BGLike/issues/389))에서 대결에서 내성으로 옮긴다. 옮긴 뒤 연출은 내성 기본값을 따른다.
- 피해·회복·이니셔티브·무작위 선택은 애니메이션도 사운드도 없다. 기존 팝업·로그·타격음(`hit.ogg`)은 그대로다.
- 명중·내성의 연출은 **굴리는 주체가 아군일 때만** 보인다(아래 [굴리는 주체](#굴리는-주체)).

## 연출 규칙

### 굴림음과 결과음

굴림음(2)과 결과음(4)은 **누적**한다. 굴림이 시작될 때 굴림음, 결과가 확정될 때 결과음이 난다.

### 굴리는 주체

주사위 연출은 **아군이 굴릴 때만** 보인다. 몬스터의 굴림은 연출 없이 기존 팝업과 로그만 남긴다.

| 굴림 | 아군이 굴림 | 몬스터가 굴림 |
|---|---|---|
| 명중 | 연출 | 팝업·로그만 |
| 흘려내기 | 연출 | 팝업·로그만 |
| 독 제거 | 연출 | 팝업·로그만 |

- 몬스터가 아군을 공격할 때의 명중굴림도 연출하지 않는다.
- 이 규칙으로 적 턴의 연출이 줄어 4배속 빠르게 보기에서 읽히는지 걱정이 줄어든다.

### 주사위 모양

면 수에 맞는 다면체 모양을 살려서 굴린다. 멈춘 윗면에 결과 숫자를 보인다. 절대성공면·절대실패면이 나오면 그 면에 강조를 더한다. 3D 모델이나 2D 스프라이트 중 무엇으로 만들지, 면 수별 자산은 개발자가 정한다.

### 기준값 표기

기준값(명중의 AC, 내성의 기준)은 **굴리기 전부터 주사위 옆에 고정으로 보인다.** 굴림이 끝나면 합계가 기준값 옆에 나타난다.

```
굴리는 중:  [주사위] + 보정 3        AC 13
멈춘 뒤:    [  9  ] + 3 = 12  <  AC 13   (빗나감 색)
```

- 기준의 이름을 붙인다. 명중은 `AC`, 흘려내기는 `공격`(맞은 공격 합계), 독 제거는 `강도`(독 강도)로 표기한다.
- 절대성공·절대실패면은 기준과 상관없이 결정되므로 비교 대신 `절대성공`·`절대실패` 글자를 보인다.

### 결과 표시

- 주사위의 결과를 숫자로 보인다.
- 성공과 실패는 색상 등으로 구분한다. 색에만 기대지 않도록 기존 글자 팝업(`빗나감` 등)을 함께 쓴다. 구체적인 색과 모양은 구현 때 정한다.
- 절대성공면·절대실패면은 일반 성공/실패와 같은 색에 **강조**를 더한다(크기, 빛 등은 구현 때 정한다).

### 명중

공격 모션 → 주사위 굴림(굴림음) → 결과 확정(결과음) → 명중이면 피해와 타격음(`hit.ogg`) 순서다. 명중 성공 시 결과음과 타격음이 연달아 난다. 빗나가면 실패 결과음만 난다.

### 유리·불리

- 주사위 2개를 **동시에** 굴린다.
- 적용되는 쪽을 강조하고 버려지는 쪽은 흐리게 한다.
- 굴림음은 주사위가 2개여도 한 번만 낸다. (임시 결정, 플레이 확인 뒤 조정한다.)

### 내성

- 흘려내기와 독 제거는 아군이 굴릴 때만 연출한다.
- 독 제거는 턴 시작에 자동으로 굴린다. 아군에 독이 겹쳐 걸렸을 때 턴 시작 연출이 길어질 수 있어 플레이 확인 항목으로 둔다.

### 빠르게 보기·건너뛰기

- 빠르게 보기(적 턴 `Space` 4배속, [#221](https://github.com/minjunkim-dev/BGLike/issues/221))는 `Engine.time_scale`을 쓴다. 주사위 애니메이션도 같은 방식으로 빨라지게 만든다.
- 건너뛰기를 쓰면 굴림 애니메이션과 굴림음은 생략한다. 결과 숫자·색상·결과음은 짧게 남긴다.
- 건너뛰기 기능은 아직 없다. 주사위 연출을 위해 먼저 만들지 않고, 그 기능을 개발할 때 함께 만든다.

### 속도

굴림 UX는 매우 빠르게 끝나야 한다. 굴림 하나의 연출 시간은 정하지 않았다. 플레이해 본 뒤 피드백으로 정한다.

## 구현 길잡이

- 굴림 결과는 `CombatChecks`가 즉시 확정한다. 연출은 확정된 `RollResult`를 보여 주기만 한다. 규칙과 연출을 섞지 않는다.
- `attack_animation`처럼 `await` 훅을 두어 연출이 끝난 뒤 다음 단계로 넘어가게 한다. 훅이 없으면 즉시 넘어가므로 테스트는 연출 없이 돌린다.
- 카테고리를 호출 지점에 코드로 박지 않고 한 곳에서 카테고리별 연출을 정한다. 대결이 확정될 때 한 곳만 고치면 된다.

## 아직 정하지 않은 것

| 항목 | 상태 |
|---|---|
| 대결 연출(만능팔, 밀치기) | 보류. 정하면 유형 7·8을 쓸지 정한다. |
| 굴림 하나의 연출 시간 | 플레이 후 피드백으로 정한다. |
| 주사위 사운드 자산 | 개발자가 고른다. 권리 확인은 [COPYRIGHT](../COPYRIGHT.md)를 따른다. |
| 색상과 강조의 구체적 모양 | 구현 때 정하고 플레이로 확인한다. |
| 기준값을 먼저 보이는 배치와 크기 | 구현 때 정하고 플레이로 확인한다. |
| 적 턴 4배속에서 결과가 읽히는지 | 몬스터 굴림은 연출이 없어 부담이 줄었다. 아군 반응 굴림(흘려내기)이 4배속에서 읽히는지는 플레이로 확인한다. |
| 소리가 겹쳐도 거슬리지 않는지(명중 성공) | 청취로 확인한다. |
