## 2. 정해진 것 ✅

### 2-1. 제품

- 턴제 타일맵 RPG, 싱글 플레이어
- 두 사람이 개발
- 전투 시스템 레퍼런스는 BG3
- 아트·UI 레퍼런스는 소드 오브 콘발라리아(도트, 격자 택티컬 화면). 에셋, 이름, UI 이미지는 복제하지 않음
- 게임 정식 이름과 세계관은 첫 플레이 가능 구간을 만든 뒤 결정

### 2-2. 이미 구현된 규칙 (1차 프로토타입)

`feat/combat-prototype` 브랜치에 있으며 `main`에는 병합하지 않았습니다.

| 항목 | 내용 |
|---|---|
| 맵 | 10×10 아이소메트릭 격자, 타일 32×16px, 높이 없음 |
| 화면 | 기준 해상도 640×360, 정수 배율, 고정 카메라 |
| 능력치 | 힘, 민첩, 건강. **보정값만** 저장 (예: 힘 +3) |
| 숙련 보너스 | +2 고정 (레벨 없음) |
| 이니셔티브 | `d20 + 민첩`. 동점이면 민첩 높은 쪽, 그다음 아군 |
| 턴 | 이동력 6칸 + 행동 1회, 순서 자유, 이동은 나눠 쓸 수 있음 |
| 이동 | 8방향, 대각선도 1칸 |
| 명중 | `d20 + 공격 보너스 ≥ AC`. 20은 치명타(피해 주사위 2번), 1은 자동 실패 |
| 전투 불능 | HP 0이면 즉시 빠짐 |
| 승패 | 한쪽 전멸 시 결과 표시와 재시작 |
| 적 AI | 사거리 안 HP 낮은 대상 공격, 없으면 가장 가까운 대상에게 접근 |
| 조작 | 한 번 누르면 미리보기, 한 번 더 누르면 확정. 이동 취소 없음. 호버에 의존하지 않음 |
| UI | 턴 순서 바, 판정 로그, 턴 종료 버튼, 명중률 % |

| 유닛 | 힘 | 민첩 | 건강 | HP | AC | 공격 | 피해 | 사거리 |
|---|---|---|---|---|---|---|---|---|
| 전사 | +3 | +1 | +2 | 12 | 16 | +5 | 1d8+3 | 인접 |
| 궁수 | +0 | +3 | +1 | 11 | 14 | +5 | 1d6+3 | 12칸 |

> Issue #4의 "2단계 후보"와 "미룬 항목"은 3장 결정으로 대체합니다.

## 3. 이번 스프린트 범위 (~2026-10-11)

### 3-1. 시험 환경

| 항목 | 결정 |
|---|---|
| 파티 규모 | 현행 유지: 2 vs 2 (전사 1, 궁수 1) |
| 시험 맵 | 현행 유지: 10×10, 장애물 없음 |
| 능력치 | 힘, 민첩, 건강 + **정신** 추가 (4종, 보정값만 저장) |

### 3-2. 포함 ✅

| 분류 | 항목 | 비고 |
|---|---|---|
| 턴 구조 | 행동 / 보조 행동 / 반응 | 현재 "행동 1회"를 3종으로 나눔 |
| 턴 구조 | 기회 공격 | 적이 인접 칸을 벗어나면 반응으로 공격 |
| 턴 구조 | 연속 이니셔티브 묶음 | 같은 편이 연속으로 턴을 받으면 묶어서 함께 진행 |
| 판정 | 유리 / 불리 | d20을 두 번 굴려 높은 값 / 낮은 값 |
| 판정 | 내성 굴림 | 스킬·상태 이상에 사용 |
| 능력 | 기본 공격 | 매 턴 사용 가능. 기회 공격 가능/불가 타입 구분 |
| 능력 | 직업별 스킬 3개 (총 6개) | **전투당 사용 횟수**로 제한 |
| 능력 | 상태 이상 1개 | 기절 |
| 위치 | 밀치기 | 1칸 밀기. 일정이 부족하면 먼저 제외 |
| 자원 | 소모품 (물약) | 보조 행동으로 사용. 일정이 부족하면 먼저 제외 |

### 3-3. 제외 ✅

| 항목 | 이유 |
|---|---|
| 높이와 고지대 | 2D 아이소에서 아트·판정 비용이 큼 |
| 주문 슬롯, 쿨다운 | 스킬 자원은 전투당 횟수로 통일 |
| 쓰러짐, 죽음 판정, 부활 | 현행 유지 (HP 0이면 즉시 전투 불능) |
| 기습 | 전투 밖 탐험 구조가 먼저 필요 |
| 점프, 던지기 | |
| 지형 표면 (불, 기름, 물, 전기) | 비용이 가장 큼. 이후 재검토 |
| 피해 타입과 저항/취약/면역 | 적 종류가 늘 때 재검토 |
| 집중 | |
| 장비, 무기 특성 | 성장 구조와 함께 정함 |
| 짧은/긴 휴식 | 전투 밖 구조가 먼저 필요 |
| 시야와 엄폐 | 시험 맵에 장애물이 없어 확인할 수 없음 |
| 넘어짐 | 발생 수단(넘어뜨리기 스킬, 밀치기 넘어뜨리기)이 모두 빠짐 |

## 5. 주의할 점

- **명칭과 에셋**: 규칙은 SRD 5e(CC-BY-4.0)를 근거로 씁니다. BG3 고유 이름, 주문 이름, 아이콘, 텍스트는 쓰지 않습니다.
- **일정**: 포함 항목이 10개이고 마감까지 9일입니다. 밀린다면 밀치기 → 소모품 순으로 뺍니다.
- **확인 방식**: 전투 조작감과 가독성은 자동 검사로 확인할 수 없습니다. 완료 기준에 직접 플레이를 넣었습니다.
